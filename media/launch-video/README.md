# GrantPipe Launch Video

HyperFrames launch video for GrantPipe, built in two aspect ratios from one project:

- Landscape: `renders/grantpipe-launch-landscape.mp4` (`1920x1080`, 20s, 30fps)
- Portrait: `renders/grantpipe-launch-portrait.mp4` (`1080x1920`, 20s, 30fps)

## Commands

```bash
npm run check
npm run render
npm run render:landscape
npm run render:portrait
npm run render:draft
```

## Notes

- No voiceover or background music is included.
- Sound design uses short ElevenLabs-generated SFX cues in `assets/audio/sfx/`,
  timed to scene transitions, UI arrivals, product surfaces, connector detail,
  and the CTA.
- The design direction is defined in `DESIGN.md`.
- Gold is reserved for the small launch workflow chip only.
- Product visuals use existing GrantPipe screenshots copied into `assets/`.
- Brand frames use the real GrantPipe SVG logo, not a recreated placeholder mark.
