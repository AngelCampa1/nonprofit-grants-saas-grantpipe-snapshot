## Method

- Orchestrator: servers + ledger + **taste judgment**. Sub-agents (lite/editor/web): capture, triage, TDD fixes, reviews. Smallest capable model.
- Per finding: severity (P0–P3) · surface · dim (A–H, PLAN §2) · issue · fix · verify. **P0 = hot-fix gate** (pause queue, fix now).
- Fix batching: **one worktree per domain** (not per finding); `shared`/`ui` batched separately (~13min gate); deploy per-domain. Spec review must confirm §3.7 consistency snapshot honored.
- Gates: TDD, 95%/file cov on touched, no `any`/TODO, buttons=pills, observability on _behavior_ changes only (pure CSS/copy exempt), spec+quality review → merge → remove worktree → deploy (Wrangler). Record last-good SHA/app before deploy.
