# Goal: Feature Buildout 2026-06 — Tier 1–3 + #18/#19/#20

**Source roadmap:** `docs/feature-opportunities-2026-06.md`

## Per-feature Definition of Done

1. PRD in `docs/grant-operating-system/` (follow existing NN-\*-prd.md pattern).
2. Schema/migration (if needed) in `packages/db`.
3. API domain (routes+service) with ≥95% per-file coverage.
4. Web UI integrated into navigation/IA (not bolted on).
5. Marketing: feature page on the Astro site (`apps/site`) — copy run through `humanizer` + `third-grade-copy`.
6. TDD throughout; `turbo typecheck test:coverage` green (use `--force` after merge).
7. Reviewed via permitted review path; every finding fixed.
8. Merged to master, worktree removed, affected apps deployed via Wrangler scripts.

## Protections (features 18/19/20 — explicit user requirements)

- **#18 Recurring Gift Engine:** use **Stripe Connect** (org is merchant of record, not GrantPipe). No money custody/liability on us. PCI via Stripe-hosted elements only.
- **#19 Proposal/Report Drafting:** **editable draft only, human submits, never auto-submit.** Full AI-use protections/disclaimers. Use **cheap models for writing (e.g. MiniMax M2.7)** via OpenRouter.
- **#20 Outcome/Impact layer:** grounding data for #19.
- All AI features: liability disclaimers, no fabricated data, grounded outputs only.
