**Highest-leverage change points** (restyle once, many pages update):

- `BaseLayout` (`packages/ui/src/site/layouts/base-layout.astro`) — header/footer chrome, meta, theme CSS injection, StickyMobileCta — touches every non-Article, non-lp page (21 direct + everything `ArticleLayout`/`CategoryHub`/`ComparisonLayout` wrap around, since those wrap `BaseLayout` too).
