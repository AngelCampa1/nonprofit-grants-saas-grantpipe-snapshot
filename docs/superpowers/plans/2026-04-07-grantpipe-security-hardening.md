# GrantPipe Security Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the current high-risk tenant-isolation flaws, reduce accidental auth/session exposure, and add repo-controlled browser/API hardening that matches the approved security baseline.

**Architecture:** The implementation stays service-first. Route middleware continues to establish coarse auth and role context, but every donor-domain relationship write or secondary lookup becomes explicitly org-scoped in the service layer. Browser hardening is split by runtime: API response headers come from Hono middleware, and static SPA headers come from Cloudflare Pages `_headers` output generated by the web build.

**Tech Stack:** Hono, Better Auth, Drizzle ORM, Zod, Cloudflare Workers, Cloudflare Pages, React 19, Vite, Vitest

**Spec:** `docs/superpowers/specs/2026-04-07-grantpipe-security-design.md`

---

## Scope and Explicit Deferrals

This plan intentionally covers repo-owned code only.

Included:

- tenant-safe donor tag mutations
- tenant-safe affiliated contact validation and lookup
- reduced auth/session exposure in app-owned code
- API security headers middleware
- static web security headers via Pages `_headers`
- regression tests for all of the above

Explicitly deferred:

- auth rate limiting and brute-force controls at the Cloudflare edge
- vendor account and infrastructure hardening
- incident response and operational runbooks

Those deferred items need a separate infra-scoped plan because the current repo has no rate-limiter binding or edge configuration surface to implement them correctly.

```ts
async function assertContactInOrg(db: Database, orgId: string, contactId: string) {
  const contact = await db.query.contacts.findFirst({
    where: and(eq(contacts.id, contactId), eq(contacts.orgId, orgId), isNull(contacts.deletedAt)),
    columns: { id: true },
  });
  if (!contact) throw new Error("Contact not found");
}

async function assertTagsInOrg(db: Database, orgId: string, tagIds: string[]) {
  const rows = await db
    .select({ id: tags.id })
    .from(tags)
    .where(and(eq(tags.orgId, orgId), inArray(tags.id, tagIds)));

  if (rows.length !== new Set(tagIds).size) throw new Error("Tag not found");
}

export async function deleteTag(db: Database, params: { orgId: string; tagId: string }) {
  const tag = await db.query.tags.findFirst({
    where: and(eq(tags.id, params.tagId), eq(tags.orgId, params.orgId)),
    columns: { id: true },
  });
  if (!tag) throw new Error("Tag not found");

  await db.delete(contactTags).where(eq(contactTags.tagId, params.tagId));
  await db.delete(tags).where(and(eq(tags.id, params.tagId), eq(tags.orgId, params.orgId)));
}

export async function addContactTags(
  db: Database,
  params: { orgId: string; contactId: string; tagIds: string[] },
) {
  await assertContactInOrg(db, params.orgId, params.contactId);
  await assertTagsInOrg(db, params.orgId, params.tagIds);
  // insert rows only after both checks pass
}

export async function removeContactTag(
  db: Database,
  params: { orgId: string; contactId: string; tagId: string },
) {
  await assertContactInOrg(db, params.orgId, params.contactId);
  await assertTagsInOrg(db, params.orgId, [params.tagId]);
  await db
    .delete(contactTags)
    .where(and(eq(contactTags.contactId, params.contactId), eq(contactTags.tagId, params.tagId)));
}
```

```ts
import { createMiddleware } from "hono/factory";

export function securityHeaders() {
  return createMiddleware(async (c, next) => {
    await next();

    c.header("X-Content-Type-Options", "nosniff");
    c.header("Referrer-Policy", "strict-origin-when-cross-origin");
    c.header("Permissions-Policy", "camera=(), microphone=(), geolocation=()");
    c.header("X-Frame-Options", "DENY");
  });
}
```

Mount it early in `apps/api/src/app.ts`, after `.onError(...)` and before route handlers.
