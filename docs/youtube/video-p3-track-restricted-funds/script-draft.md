### The question a report can't answer

[VISUAL: Warm paper. A line: "This money is only for the after-school program." Below it, a question in emerald: "How much is left, and can you prove it?"]

A restriction is a promise. A funder hands you money and says, use this only for one thing. Now you have to be able to answer one question at any moment. How much of that money is left, and can you prove where the rest went? A normal activity report shows what moved. It does not answer that question. Today I'll show you how to track restricted funds so you can.

I build grant compliance software, so I had to learn exactly how this money moves. I'm not an auditor. You're getting the version a busy director needs.

### What restricted really means

[VISUAL: Two buckets. Emerald "Without donor restrictions — free money". Ochre "With donor restrictions — promised money". Faded struck-through "(old rule: 3 groups)".]

Restricted means a donor or grantor tied the money to a purpose or a time. Only they can lift that limit. Nonprofit books sort money into two groups now: with donor restrictions, and without. Promised money and free money. If an old guide says three groups, it's out of date. The rule changed to two. And money your board sets aside isn't restricted. The board can change its own mind. Only an outside funder can truly restrict a gift.

### What tracking it actually takes

[VISUAL: A running balance strip: Beginning → + Additions → − Releases → Ending. A class report sits beside it with a red "shows activity, not balance" tag.]

Here's the part people get wrong. To track a restriction, you need a running balance for each award. You start with the award. You add anything new. You subtract what you spend on the purpose, which accountants call a release. And you end with a number you can defend. A release isn't new money. It's just the promise being kept. One big checking account and a class memo won't give you that per-promise balance. That's the gap.

### Set up the fund

[VISUAL: Real screen — /funds list, card view. Ken-Burns push-in. Spotlight the "Add fund" button, then the Add-fund dialog with the type select open showing the three types.]

So let me show you one way to do it, in the real app. This is the funds list. Each fund is one promise, one purpose. To make one, you add a fund, give it a name, and pick its type. Unrestricted, temporarily restricted, or permanently restricted. The same two ideas from before, just named the way the rules name them. You can filter the list by type, so the promised money is easy to find.

### See the balance per award

[VISUAL: Real screen — fund detail /funds/:id. Spotlight the three cards: Allocated, Spent, Balance. Then pan to Source Allocations and the Expense Ledger.]

Open a fund, and here's the answer to half the question. Three numbers. Allocated, what came into this fund. Spent, what's gone out. Balance, what's left. That balance isn't typed in. The app works it out from the grants feeding the fund and the spending against it. Below, you can see which grants fund this, and every expense charged to it. That's how much is left, live.

### Prove the restriction

[VISUAL: Real screen — Restrictions tab. Spotlight a restriction term: beginning balance, additions, releases, ending balance. Then a release row with its evidence link.]

Now the other half. Can you prove it? The Restrictions tab keeps the running balance we drew earlier. Beginning, additions, releases, ending. When you spend on the purpose, you record a release, and you attach the evidence right there. So when a funder or auditor asks, the proof is already sitting next to the number. This lives in GrantPipe's restriction tracking, which is part of the plan that includes it, not every plan.

### One thing to remember

[VISUAL: Recap card. Big line: "A balance you can defend, per promise." Chips: "Start, add, release, end", "The app does the math", "Evidence next to the number". GrantPipe wordmark + soft chip "Restricted Fund Tracking Spreadsheet — we'll send it to your inbox".]

That's it. Tracking restricted funds comes down to one thing. A balance you can defend for every promise. Start it, add to it, release as you spend, end on a number with the evidence attached. A spreadsheet can do this when you're small. A system does it for you when you're not. That's the kind of thing we built GrantPipe to handle. But the discipline matters more than any tool.
