# GrantPipe Getting Badges Pack

Verified on 2026-05-15.

This folder contains the copy, requirements, assets, and QA notes needed to submit GrantPipe to SaaSHub, AlternativeTo, BetaList, Product Hunt, and G2.

## Fastest Submission Order

1. SaaSHub
   - Submit first because the profile is straightforward, competitor-driven, and useful for alternatives pages.
   - Use `platforms/saashub.md`.
2. AlternativeTo
   - Submit next because the listing depends on clear alternatives and tags.
   - Use `platforms/alternativeto.md`.
3. BetaList
   - Submit only if GrantPipe can credibly meet BetaList's recency rule.
   - Use `platforms/betalist.md`.
4. G2
   - Request or claim the profile early because G2 verification can take several business days.
   - Use `platforms/g2.md`.
5. Product Hunt
   - Prepare the draft now, but only schedule when the launch date, YouTube video URL, and outreach list are ready.
   - Use `platforms/producthunt.md`.

## Claim Boundaries

Use only these claims:

- GrantPipe is a compliance-first grant management system.
- It brings donor records, grants, restricted funds, compliance deadlines, evidence, reporting, and fund accounting into one workspace.
- Grants.gov federal opportunity search is included.
- Non-federal opportunities can be tracked manually or imported from CSV.
- Foundation prospect context can use public nonprofit filings where available.
- It is built for Executive Directors, Development Directors, grants managers, and finance leads at mid-sized nonprofits with roughly $500K-$10M annual budgets.
- It is built from the founder-builder perspective.

Do not claim:

- Customer logos, public customer counts, awards, rankings, or testimonials.
- Nonprofit operator experience.
- An Instrumentl-scale proprietary private foundation, corporate, state, local, or association grant database.
- Guaranteed badge outcomes before the required reviews or launch results exist.
