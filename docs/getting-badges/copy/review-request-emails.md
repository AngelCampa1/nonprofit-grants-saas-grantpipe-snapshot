# G2 Review Request Emails

Use these only for real users who have used GrantPipe. Do not ask for a positive review. Ask for an honest review.

## Initial Ask

Subject:

```text
Could you leave an honest GrantPipe review on G2?
```

Body:

```text
Hi [Name],

I am setting up GrantPipe's G2 profile so nonprofit teams can evaluate the product from real user feedback, not just our website copy.

If you have used GrantPipe enough to have a fair opinion, would you be willing to leave an honest review here?

[G2 review link]

No need to make it polished. The most useful review is specific: what you used GrantPipe for, what worked, what was confusing, and who you think it is or is not a fit for.

Thank you,
Angel
```

## Five-Day Follow-Up

Subject:

```text
Quick follow-up on the GrantPipe G2 review
```

Body:

```text
Hi [Name],

Quick follow-up on the G2 review ask. If you have a few minutes this week, your honest feedback would help teams evaluating GrantPipe understand where it fits and where it still needs work.

Here is the review link again:

[G2 review link]

If now is not a good time, no problem.

Thank you,
Angel
```

## Review Prompt For Users

```text
If you leave a review, the most helpful details are:

- What kind of nonprofit workflow you used GrantPipe for.
- Which parts of the product you touched.
- Whether it helped connect donors, grants, restricted funds, deadlines, evidence, or reporting.
- What you would want improved.
- Who you think GrantPipe is a good fit for.
```
