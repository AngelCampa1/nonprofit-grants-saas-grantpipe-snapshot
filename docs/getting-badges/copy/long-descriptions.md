# Long Descriptions

Each platform gets distinct copy. Do not paste the same long description everywhere.

## SaaSHub

```text
GrantPipe is a compliance-first alternative to donor-only CRMs like Bloomerang, DonorPerfect, and Neon CRM. It is built for grant-funded nonprofits that need donor records, active grants, restricted funds, compliance deadlines, evidence, reporting, and fund accounting in the same workspace.

Most nonprofit CRMs handle the donor relationship, then leave grant operations in spreadsheets, calendars, and accounting side files. GrantPipe keeps the grant record connected to the donor, the fund, the reporting deadline, and the documentation the team needs later.

Core workflows include donor CRM, active grant tracking, Grants.gov federal opportunity search, manual and imported non-federal opportunity tracking, restricted-fund views, compliance calendars, evidence bundles, and reporting workflows.

GrantPipe is built for mid-sized nonprofits with roughly $500K-$10M annual budgets, especially teams managing several active grants without wanting a custom Salesforce build or a consultant-heavy implementation.
```
