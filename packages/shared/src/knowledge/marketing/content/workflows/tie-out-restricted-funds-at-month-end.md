Restricted funds should not wait for year-end. A monthly tieout keeps donor limits, grant terms, releases, and cash context current while staff still remember what happened.

The workflow is simple: prove the beginning balance, add new activity, subtract supported releases, record corrections, and explain the ending balance.

This workflow supports month-end close and board reporting. It is not accounting advice. Use your policy and adviser for final decisions.

## Step 1: prove the beginning balance

Start with the prior month ending restricted balance. It should match the current month beginning balance. If it does not, find out why before adding new activity.

Common reasons include late journal entries, fund code changes, merged funds, or prior period corrections. Write the reason in the tieout.

GrantPipe can help keep restricted funds, deadlines, reporting, and audit evidence tied to one record. The tieout still needs finance review, but the support should be close to the balance.

## Step 2: add new restricted activity

List new restricted gifts, grants, pledges, and corrections. Tie each line to a source document.

For each item, capture:

- Donor or funder
- Amount
- Date
- Restriction type
- Fund code
- Source document
- Release trigger
- Owner

Do not add a restricted line with no source. If the source is missing, add the item to the open list and assign an owner.

## Step 3: review releases

Pull all release from restriction entries for the month. Each release should have a reason and support.

If the release is based on program spending, tie it to expense detail. If it is based on time, tie it to the date. If it is based on a campaign or grant milestone, save proof that the milestone was met.

Do not use releases to make a budget look cleaner. Releases should follow the restriction.

## Step 4: compare to cash and receivables

Restricted fund balances and cash balances can differ. A restricted pledge may be receivable. A grant reimbursement may be earned but unpaid. An advance may put restricted cash in the bank before spending happens.

Add a short cash check:

- Cash received this month
- Open receivables
- Open payables
- Restricted cash held
- Cash expected soon

This helps leaders understand why restricted net assets may not equal bank cash.

## Step 5: check deadlines and reports

Restricted funds often carry dates. Review funder reports, grant closeout dates, spending deadlines, donor reports, and board reporting needs.

If a deadline is close, add it to the open item log. A clean balance is not enough if the report is late.

## Step 6: resolve exceptions

Exceptions should have owners and due dates. Common exceptions include missing source support, negative fund balance, release with no evidence, old receivable, fund code mismatch, and gift purpose conflict.

Avoid "pending" as the whole note. Write the next action. Example: "Development will confirm donor purpose by July 3."

## Step 7: get review approval

A reviewer should check material balances, releases, and open items. The review can be a system approval, signed checklist, or dated email.

Save the approval with the tieout. The next audit request should not depend on someone remembering who reviewed the schedule.

## Add a short leadership note

After review, write a short note for the executive director or treasurer. The note should name the restricted balance, the largest changes, any deadline risk, and any cash pressure.

Keep the note separate from the ledger detail. Leaders need to know what needs action. They do not need every transaction. A good note says, "Three restricted funds need support before close. One grant report is due July 15. Restricted cash cannot cover the full August payroll plan."

This note also helps the board packet. It gives leaders the plain story before the full report is built.

## Outputs

The finished workflow produces a restricted fund rollforward, release support list, cash context note, open item log, and reviewer approval.

## Common failures

The biggest failure is treating cash as the whole answer. Cash matters, but restricted net assets may include receivables or releases that have not moved cash.

Other failures include missing release support, rolling forward the wrong beginning balance, using old fund codes, and leaving open items with no owner.

## Review questions

Before closing the tieout, ask five questions. Does the beginning balance match the prior approved schedule? Does each new restricted gift or grant have source support? Does each release have purpose or time evidence? Do open items have owners? Would an auditor understand the schedule without a meeting?

If any answer is no, keep the tieout open. A small delay is better than closing a restricted fund schedule that staff cannot explain later.

## Automation ideas

Automation can compare beginning and ending balances, flag releases without support, alert on negative balances, and create review tasks by fund owner. It can also link donor CRM notes to finance records.

Automation should help staff find evidence faster. It should not decide whether a restriction has been met without review.
