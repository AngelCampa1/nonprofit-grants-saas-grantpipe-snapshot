# Review program attendance evidence

Attendance evidence can support many grant reports. It shows who came, when they came, and which activity happened. It can also cause report errors when teams rush the review.

This workflow helps program and grants staff review attendance before the number appears in a report.

## Step 1: gather the source records

Collect all attendance sources for the report period. These may include sign in sheets, online rosters, class exports, program logs, partner reports, or case system records.

Save the source name, owner, and date pulled. If a partner provides the file, save the date received.

Do not start with a final count someone typed into an email. Find the source behind it.

## Step 2: confirm the report period

Apply the funder report period. Check the field used for dates.

For attendance, the session date usually matters. A registration date may not prove that the person attended. A data entry date may only show when staff entered the record.

Save the start date, end date, and date field.

## Step 3: confirm the count unit

Read the report requirement. Does it ask for people, visits, households, sessions, or completions?

This step matters because one roster can support more than one count.

Example:

- Ten people attend five sessions each.
- The report could count ten unique people.
- The report could count fifty visits.
- The report could count five sessions.

Use the count the funder asks for.

## Step 4: review no shows and partial attendance

Rosters often include people who registered but did not attend. Some programs also count partial attendance differently.

Set a rule:

- Registered only
- Attended any part
- Attended full session
- Completed required number of sessions

Use the rule that matches the grant. Save it with the evidence.

## Step 5: check duplicates

Duplicates can come from spelling changes, duplicate registrations, merged households, or repeated sessions.

If the report asks for unique people, use a stable ID when possible. If you must review by name, protect the file and document the matching method.

Do not remove duplicates without a note. A later reviewer needs to know what changed.

When duplicates are unclear, ask the program owner before changing the count. A repeated row may be a real second visit. It may also be a duplicate registration. The source alone may not answer that question.

Keep the duplicate note short. List the record, action, reason, reviewer, and date. That is enough for most report packets.

## Step 6: protect the roster

Attendance files may include names, ages, school names, addresses, or service needs. The report packet may only need a summary count.

Before saving evidence, remove fields that do not support the count. Store raw files in the approved system. Limit access to staff who need the detail.

If a paper sign in sheet is scanned, check that the scan is readable before the paper is filed. If the sheet includes phone numbers or other private details, store it with restricted access. The report packet can use a summary count instead.

GrantPipe can help keep attendance evidence, report deadlines, and approval notes tied to the grant record instead of spread across inboxes.

## Step 7: compare to the narrative

Read the draft report next to the attendance evidence. The narrative should say what the roster proves.

If the roster proves attendance, write attendance. If the report claims skill gain, use survey or assessment evidence too.

Avoid broad lines like "participants succeeded" unless the source supports that result.

Also watch for mixed time periods. A sentence may combine attendance from one quarter with outcomes from another quarter. If the periods differ, say so or split the sentence.

If attendance changed sharply from the last report, add a short note. Name the cause if staff know it. Examples include a closed site, added class, weather closure, or late partner file.

## Step 8: approve and save

The program owner should approve the count and meaning. The grants manager should approve that the number fits the funder question.

Save:

- Source files or summaries
- Count rule
- Date range
- Duplicate check
- No show rule
- Privacy note
- Approval
- Final report number

Strong attendance evidence is easy to trace. It tells a reviewer what was counted, why it was counted, and who approved it.
