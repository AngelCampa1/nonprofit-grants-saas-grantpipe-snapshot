Match should not be reported from memory. It should be reported from support.

Use this workflow before each report that includes cash match, in-kind match, volunteer time, donated space, or another match source.

## Step 1: identify the source

Name the source, amount, date, grant, and report period.

If the source is another grant, pull both award terms. The source grant must allow the use.

## Step 2: check timing

Confirm the match happened during the allowed period. A late donation or future pledge may not count for the current report.

If timing is unclear, do not report the match until the question is resolved.

## Step 3: support the value

Cash match needs payment or deposit support. In-kind match needs valuation support.

Volunteer time should include person, date, service, hours, rate, and approval. Donated space should include the basis for the value.

## Step 4: prevent double counting

Check the match tracker before reporting. The same source should not be counted twice.

If one source supports more than one award, document the split.

## Step 5: tie out to the report

Match the support packet to the report line. Save the worksheet, reviewer note, and final report.

Use the [match source allowability guide](/resources/guides/nonprofit-match-source-allowability-guide) for the policy test.

## Match support worksheet

Use the same worksheet for every report that includes match.

| Field              | What to record                                                            |
| ------------------ | ------------------------------------------------------------------------- |
| Source             | Cash, payroll, volunteer time, donated space, supplies, or other grant.   |
| Amount             | Dollar value reported.                                                    |
| Date               | When the source was paid, donated, worked, or used.                       |
| Value basis        | Payroll rate, volunteer rate, donor record, lease rate, or other support. |
| Award fit          | Why the source supports this grant.                                       |
| Double count check | Where else the source was reviewed or reported.                           |
| Reviewer           | Person approving the match support.                                       |

Keep the worksheet with the report. It should be easy to trace each match line back to support.

## Cash match

Cash match is usually easier to support, but it still needs review. Confirm the cash is not restricted for another purpose. Confirm it was spent on the grant activity, not just held in the bank.

If the cash came from a donor, review the gift restriction. A gift restricted to one program may not be available for another program.

## In-kind match

In-kind match needs more care. Keep the donor record, valuation support, and proof that the good or service was used for the grant.

Volunteer time should include the volunteer name, date, hours, service, rate basis, and approval. Donated space should include dates of use and a fair value basis.

Do not use a rate just because it helps close the match gap. The rate needs to fit the service or item.

## Source-backed caveats

2 CFR 200.306 requires match to be verifiable from records, not paid by the federal government under another award unless allowed, and necessary and reasonable for the award.

2 CFR 200.403 still matters because match costs must be allowable. A cost does not become good match just because the nonprofit paid for it.

2 CFR 200.434 covers contributions and donations. Use it when the match source includes donated services, property, or space.

## When to pause the report

Pause before submission if:

- the source has no support
- the value is not documented
- the timing falls outside the award period
- another grant already used the same source
- the donor restriction conflicts with the grant
- the report line does not tie to the match tracker

GrantPipe can help by keeping the source, value, approval, and report tie-out on the grant record. That does not make the source allowable by itself. It makes the review visible.

## Closeout review

Before closeout, compare total required match to total supported match. Do not rely on the last report alone. Pull the tracker, the report history, and the support packets.

Look for match that was promised but never received. Also look for match that was received but never used for the grant activity.

If the organization is short, raise the issue before the final report. The funder may require a correction, budget change, or other written direction.
