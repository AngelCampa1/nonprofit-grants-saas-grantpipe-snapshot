An EPA reporting calendar should be built from the award, not from memory. The award terms tell the team what is due, when it is due, who must prepare it, and what support belongs behind it.

The calendar should cover more than report due dates. It should include the work needed before each due date: ledger close, draw review, match review, performance data, approvals, and submission proof.

Use this workflow during award setup. Then connect each financial report to the [SF-425 workflow](/workflows/prepare-sf-425-quarterly-report) if the award uses that form.

## Step 1: collect the source documents

Pull the EPA award, amendments, general terms and conditions, program terms, and any reporting instructions from the grant office.

Save the documents in the award file. The calendar should point back to the source for each date.

If the award has special conditions, add them to the review list. A special condition may create a task before regular reporting starts.

## Step 2: list required reports

Create a report list before choosing calendar dates. Include financial reports, performance reports, technical reports, deliverables, continuation tasks, and closeout reports.

For each report, write the name, period covered, due date rule, submission system, owner, approver, and source document.

If a due date is based on the end of a period, write the rule and the calculated date. This helps when the award period changes.

## Step 3: add preparation tasks

A due date alone is not enough. Add work dates before each due date.

For a financial report, add ledger close, drawdown tieout, cash review, match review if needed, draft report, finance review, program review, and submission.

For a performance report, add data pull, program narrative, outcome check, leadership review, and submission.

Give each task an owner. A calendar with no owners is only a reminder list.

## Step 4: add draw and cash reviews

EPA awards may include reimbursement or advance payment activity. Add a draw review before each cash request.

Tie this task to the [federal drawdown review workflow](/workflows/review-federal-drawdown-before-request). The draw file should support the cash line that later appears in the financial report.

If cash is received late or costs move between periods, add a note to the next report task.

## Step 5: add closeout early

Closeout should appear on the calendar at award setup. Do not wait until the project ends.

Add final ledger review, final performance report, final financial report, equipment review if any, match review if any, and record retention note.

Use the [close federal award file workflow](/workflows/close-federal-award-file) to build the final checklist.

## Step 6: set reminders and review rhythm

Set reminders far enough ahead for the work. A large performance report may need weeks. A simple financial report may need a few days after ledger close.

Review the calendar monthly. Confirm which reports were filed, which were accepted, and which dates changed.

When EPA accepts a report or asks for a revision, save that note and update the calendar.

## Step 7: keep proof with each task

Each completed task should have proof. For a report, keep the submitted copy, support worksheet, approval, attachments, and confirmation.

For a review task, keep the checklist or notes. For a changed date, keep the email or award amendment that changed it.

The calendar should show status, but the file should hold the proof.

## Make the calendar usable

Keep the calendar simple enough that staff will update it. Use columns for date, task, owner, source, status, support needed, and proof link.

Avoid hidden due dates in emails. If a date matters, put it in the calendar and link the source.

## Add a change log

EPA award dates can change after amendments, agency emails, or accepted report revisions. Add a change log to the calendar.

For each change, record the old date, new date, source, person who made the update, and date updated. Link the email, amendment, or agency notice.

This keeps the team from arguing later about which date is right. It also helps a reviewer see that a missed old date was replaced by a documented new one.

Review the change log during the monthly calendar check. If the source is missing, add it before the memory of the change fades.

Assign one person to approve date changes.

Put that owner in the calendar, not only in email.

GrantPipe can help keep EPA report dates, owners, support files, and status notes tied to the award. It does not replace reading the award terms, but it can keep the reporting work from being scattered across inboxes and spreadsheets.
