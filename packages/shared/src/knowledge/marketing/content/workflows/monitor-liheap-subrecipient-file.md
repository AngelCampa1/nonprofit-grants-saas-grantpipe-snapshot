LIHEAP subrecipient monitoring should leave a file that explains what was checked, what was found, and what happened next.

The file is not just a compliance binder. It is how the pass-through entity proves it reviewed the subrecipient in a way that matched risk.

Start with the [subrecipient risk review](/workflows/document-subrecipient-risk-review). The monitoring file should follow that risk rating and the plan tied to it.

## Step 1: confirm the subrecipient role

Review the agreement. Confirm the entity is a subrecipient, not a contractor. A subrecipient carries out part of the federal program.

Then confirm the subaward amount, period, scope, reporting duties, payment terms, and any LIHEAP-specific requirements.

Save the agreement and any amendments in the file. Monitoring should test against the actual terms, not a generic checklist.

## Step 2: read the risk review

Open the current risk review. Note the risk rating and the reasons for it.

If the subrecipient had prior findings, late reports, staff turnover, or system changes, the monitoring should address those items. If risk has changed, update the risk review.

The file should show a clear link: risk facts, monitoring steps, results, and follow-up.

## Step 3: check required reports

List every report due for the review period. Include fiscal reports, performance reports, client service reports if used, and any special reports in the subaward.

Check whether each report was submitted on time. Then test whether selected report totals tie to source records.

If the subrecipient reports households served, benefits paid, or administrative costs, pick a sample and trace it to support.

## Step 4: test fiscal support

Pull a sample of costs charged to the subaward. The sample should include larger costs, unusual costs, and routine costs.

For each selected cost, check invoice or payroll support, payment proof, allocation basis, period, budget fit, and approval.

Administrative costs deserve a careful look because LIHEAP awards often track benefit and administrative spending separately. Use the subaward terms and program rules when testing.

## Step 5: review eligibility or service support

If the subrecipient determines eligibility or delivers benefits, test selected files. Check that the file supports the service or benefit reported.

Protect private client data. The monitoring record should prove the test happened without copying more personal data than needed.

Use a file number, test date, and result. Do not put sensitive details in broad shared folders.

## Step 6: document findings and concerns

Write findings in plain language. Name the condition, the rule or term, the cause if known, and the required action.

Not every issue is a formal finding. Some items may be notes or technical help. Label them clearly.

Set due dates for corrective action. Assign an owner for follow-up.

## Step 7: close the loop

Review the subrecipient's response. Save the response, support, and your decision.

If the issue is fixed, mark it closed with the date. If it is not fixed, escalate under the subaward terms and your monitoring policy.

Keep the final monitoring file with the subaward. It should include the plan, checklist, tests, results, findings, follow-up, and closure.

## Make monitoring match risk

Low-risk subrecipients may need a lighter review. Higher-risk subrecipients may need more testing, more frequent reports, or a site visit.

Do not use the same review for every subrecipient. 2 CFR 200.332 expects monitoring that responds to risk.

## Keep a rolling monitoring summary

Create a one-page summary for each LIHEAP subrecipient. Update it after each review, report problem, or corrective action.

Include the current risk rating, open findings, late reports, tested costs, questioned costs if any, and next monitoring date. This summary helps leadership see which files need attention without reading every test sheet.

Also record positive movement. If a subrecipient clears findings and submits clean reports for several periods, the file should show that improvement.

Use the summary when planning the next review. It keeps the monitoring plan tied to actual results, not old assumptions.

## Review payment holds and remedies

If monitoring finds serious or repeated issues, review the subaward remedies before the next payment. A remedy may include more support, extra reports, training, payment conditions, or other steps allowed by the agreement.

Document the reason before using a remedy. Also document when the remedy ends. This helps the subrecipient understand the path back to normal monitoring.

If funds are questioned, keep the calculation and the final decision in the same file. That record should show whether the amount was repaid, allowed after more support, or handled through another approved step.

GrantPipe can help keep risk reviews, monitoring tasks, reports, findings, and follow-up dates tied to the subaward. It does not replace program judgment, but it helps the team show that follow-up happened.
