FEMA NSGP purchases often include cameras, access control, lighting, barriers, radios, or other security items. The grant file needs more than an invoice.

It should show that the item was approved, bought under the right process, installed or placed where expected, and tracked after purchase.

Use this workflow with the [federal equipment inventory guide](/resources/guides/federal-grant-equipment-tagging-inventory-guide) when setting up the asset file.

## Step 1: confirm the approved scope

Start with the FEMA NSGP award, investment justification, approved budget, and any state administrative agency instructions.

List each approved item or project category. Compare planned purchases to that list before ordering.

If the team wants to buy a different item, pause. Check whether approval is needed before the change. Do not assume a similar security item is allowed.

## Step 2: connect procurement support

Keep the procurement file with the equipment record or link to it. The file may include quotes, bids, vendor selection notes, conflict checks, approvals, and purchase orders.

The right support depends on your policy and federal procurement rules. The key point is traceability. A reviewer should see how the vendor was chosen.

If an emergency or sole-source process was used, keep the justification and approval.

## Step 3: record asset details

Create an asset record as soon as the item is received or installed. Include description, manufacturer, model, serial number if available, acquisition date, cost, funding source, location, condition, and person or department responsible.

For installed systems, include location and installation support. For software or licenses, record term, users, and security purpose.

If the item is part of a larger system, record both the system and major components when useful.

## Step 4: tie cost to payment

Match the asset record to the invoice, payment proof, and ledger line. If one invoice includes several items, split the cost in the inventory.

If the award paid part of the cost and the organization paid part, record both funding sources.

This matters later if the item is sold, moved, replaced, or disposed of.

## Step 5: verify location and use

After installation or receipt, confirm the item is where the record says it is. For facility security items, take care not to create public security risk in file names or shared notes.

The record should prove use without exposing sensitive security layouts to people who do not need them.

Use a controlled folder for detailed maps, camera locations, or access control records.

## Step 6: review before closeout

Before closeout, compare the approved budget, procurement file, ledger, and asset list. Every equipment item charged to the award should appear in the inventory.

Check condition and location. If an item was not installed, was returned, or changed, document the reason and the approval.

Use the [close federal award file workflow](/workflows/close-federal-award-file) to connect the equipment review to final reporting.

## Step 7: keep retention and disposition notes

Federal equipment rules may apply after the grant ends. Keep notes on record retention, inventory review, insurance, and disposition.

If equipment is later sold, replaced, stolen, damaged, or no longer needed, review the rules before action. Save approvals and final records.

## A simple record format

A small nonprofit can use a clear spreadsheet if it is controlled and backed by source files. The spreadsheet should include one row per asset or major component.

Do not wait until year-end to build it. The best time to create the record is when the item is received.

## Review access to the file

NSGP records can include sensitive security details. Decide who needs access to the full file and who only needs cost records.

Finance may need invoices, payment proof, and funding source. Facilities or security staff may need locations, serial numbers, and system details. Leadership may need status and closeout proof.

Use separate folders when needed. Keep the detailed security layout or camera placement information limited to staff with a clear need.

This protects the organization while still keeping the grant file complete. The file should prove compliance without making the security plan easier to misuse.

## Schedule an annual inventory check

Add an annual date to verify each NSGP asset. Confirm location, condition, use, and whether the item is still needed for the approved security purpose.

If an item moved or failed, update the record and save the reason. If it is missing, follow the organization's loss and insurance process.
