## How to Use This Scorecard

AI tools are proliferating faster than nonprofits can evaluate them. A new tool gets featured in a sector newsletter, a board member asks why you're not using it, and suddenly you're in a vendor demo without a clear framework for what "good" looks like.

This scorecard gives you that framework. It covers four use cases - grant writing assistance, donor communication, data analysis, and administrative automation - with specific scoring criteria for each. Use it to evaluate one tool at a time, or to compare multiple tools side by side.

**How to score:**
Each criterion is scored 1-5.

- 1 = Does not meet this criterion
- 2 = Partially meets; significant gaps
- 3 = Meets the criterion adequately
- 4 = Meets well; minor gaps
- 5 = Exceeds expectations; strong fit

**Weights:** Not all criteria are equal. For nonprofits handling donor data and grant funds, data privacy and security criteria should be weighted more heavily than any feature criterion. The scorecard notes which criteria are weighted.

## Use Case 1: Grant Writing Assistance

### Scoring Criteria

**Criterion 1: Ability to incorporate organizational context**
Can the tool learn (or be prompted with) your organization's theory of change, current programs, past grant language, and budget details - and produce output that reflects your specific work rather than generic nonprofit language?

| Score | Description                                                           |
| ----- | --------------------------------------------------------------------- |
| 1     | Generic outputs; no way to customize with organizational context      |
| 2     | Can accept some context but outputs remain largely generic            |
| 3     | Accepts detailed prompts; outputs reflect context with supervision    |
| 4     | Retains organizational context across sessions or via document upload |
| 5     | Learns organizational voice and context; minimal supervision required |

**Criterion 2: Quality of narrative output for a foundation grant**
Does the output require significant editing to be submission-ready, or does it produce usable first drafts?

| Score | Description                                                     |
| ----- | --------------------------------------------------------------- |
| 1     | Output is generic and unusable; significant rewrite required    |
| 2     | Output is a useful starting point but requires major revision   |
| 3     | Output is 50-70% usable; requires moderate editing              |
| 4     | Output is 70-85% usable with targeted editing                   |
| 5     | Output is 85%+ usable; primary editing is voice and specificity |

**Criterion 3: Budget narrative assistance**
Can the tool help draft budget justification language for specific line items?

| Score | Description                                                     |
| ----- | --------------------------------------------------------------- |
| 1     | No budget assistance capability                                 |
| 2     | Generic budget language only                                    |
| 3     | Useful budget language with specific cost details provided      |
| 4     | Produces line-item justifications that match proposal narrative |
| 5     | Integrates budget data to produce coherent budget narrative     |

**Criterion 4: Compliance with funder requirements**
Can the tool format output to specific page limits, word counts, or funder-specified section structures?

| Score | Description                                                               |
| ----- | ------------------------------------------------------------------------- |
| 1     | No length/format controls                                                 |
| 2     | Rough length control only                                                 |
| 3     | Reliably produces output within specified length constraints              |
| 4     | Adapts to funder-specific section headers and requirements                |
| 5     | Can reference funder guidelines directly and structure output accordingly |

**Criterion 5: Avoiding hallucinated statistics**
Does the tool produce fabricated statistics, citations, or organizational claims that would be embarrassing or disqualifying in a grant submission?

| Score | Description                                                               |
| ----- | ------------------------------------------------------------------------- |
| 1     | Regularly produces specific claims without basis; not safe for grant work |
| 2     | Occasionally produces unsupported claims; requires careful review         |
| 3     | Generally avoids unsupported claims when prompted appropriately           |
| 4     | Rarely produces unsupported claims; easy to verify output                 |
| 5     | Consistently signals uncertainty; never fabricates specific claims        |

**Grant Writing Assistance Total: \_\_ / 25**

## Use Case 2: Donor Communication

### Scoring Criteria

**Criterion 1: Personalization at scale**
Can the tool generate individualized donor communications (thank-you letters, update messages, appeal segments) using donor data you provide?

| Score | Description                                                      |
| ----- | ---------------------------------------------------------------- |
| 1     | No personalization; generic output only                          |
| 2     | Basic merge-field-style personalization                          |
| 3     | Can vary content based on giving history and segment provided    |
| 4     | Produces meaningfully differentiated content across segments     |
| 5     | Produces individualized content that reads as genuinely personal |

**Criterion 2: Tone calibration for nonprofit voice**
Does the tool produce output that matches a nonprofit's voice (rigorous, mission-focused, not commercial) without extensive prompting?

| Score | Description                                                                |
| ----- | -------------------------------------------------------------------------- |
| 1     | Outputs sound commercial or generic; requires significant rework           |
| 2     | Nonprofit tone possible but requires detailed prompting                    |
| 3     | Reasonable nonprofit voice with standard prompting                         |
| 4     | Consistent nonprofit voice; adjusts to organizational style guidance       |
| 5     | Produces output indistinguishable from experienced nonprofit communicators |

**Criterion 3: Subject line and email optimization**
Does the tool assist with subject lines, preview text, and email structure in ways that improve open rates?

| Score | Description                                                                    |
| ----- | ------------------------------------------------------------------------------ |
| 1     | No email optimization features                                                 |
| 2     | Generic email writing assistance only                                          |
| 3     | Produces multiple subject line options; explains rationale                     |
| 4     | Recommends A/B testing approaches; suggests optimization based on content type |
| 5     | Integrates with your email platform data to suggest data-driven optimizations  |

**Criterion 4: IRS compliance awareness**
Does the tool understand and avoid common compliance errors in donor communications (e.g., overstating tax deductibility, fabricating impact claims)?

| Score | Description                                                       |
| ----- | ----------------------------------------------------------------- |
| 1     | No compliance awareness; produces potentially misleading language |
| 2     | Produces compliant language when explicitly prompted              |
| 3     | Generally avoids compliance errors with standard prompts          |
| 4     | Flags potential compliance issues in its output                   |
| 5     | Proactively structures output to meet acknowledgment requirements |

**Criterion 5: Integration with donor database**
Can the tool connect to or import data from your donor database to populate communications with giving history, program interests, and relationship notes?

| Score | Description                                                   |
| ----- | ------------------------------------------------------------- |
| 1     | No integration; manual data entry required                    |
| 2     | CSV import only; manual workflow                              |
| 3     | CSV or API import with some automation                        |
| 4     | Native integration with major nonprofit CRMs                  |
| 5     | Real-time integration; updates communications as data changes |

**Donor Communication Total: \_\_ / 25**

## Use Case 3: Data Analysis

### Scoring Criteria

**Criterion 1: Donor data pattern recognition**
Can the tool identify meaningful patterns in giving data (retention rates, lapse indicators, upgrade candidates) without requiring a data scientist?

| Score | Description                                                                     |
| ----- | ------------------------------------------------------------------------------- |
| 1     | No analysis capability; requires external tools                                 |
| 2     | Basic aggregation and filtering only                                            |
| 3     | Identifies trends when data is well-structured; requires some interpretation    |
| 4     | Surfaces meaningful patterns with plain-language explanations                   |
| 5     | Proactively identifies opportunities (upgrade candidates, lapse risk) from data |

**Criterion 2: Report generation from raw data**
Can the tool produce board-ready reports, funder reports, or internal dashboards from your data without requiring SQL or specialized technical skills?

| Score | Description                                                                 |
| ----- | --------------------------------------------------------------------------- |
| 1     | No report generation; raw data only                                         |
| 2     | Basic charts and tables; limited formatting                                 |
| 3     | Produces structured reports with some customization                         |
| 4     | Produces board-ready reports with consistent formatting                     |
| 5     | Produces fully formatted, narrative-enhanced reports ready for distribution |

**Criterion 3: Grant expenditure analysis**
Can the tool analyze grant spending against budget, flag variances, and project end-of-period balances?

| Score | Description                                                           |
| ----- | --------------------------------------------------------------------- |
| 1     | No grant analysis capability                                          |
| 2     | Manual calculation assistance only                                    |
| 3     | Analyzes data from uploaded spreadsheets; produces variance summaries |
| 4     | Connects to financial data and produces real-time grant dashboards    |
| 5     | Automated alerts for budget variances; projection modeling included   |

**Criterion 4: Data accuracy and hallucination risk**
When analyzing your data, does the tool reliably produce accurate calculations, or does it fabricate numbers?

| Score | Description                                                     |
| ----- | --------------------------------------------------------------- |
| 1     | Regularly produces calculation errors; high verification burden |
| 2     | Occasional calculation errors; requires audit of outputs        |
| 3     | Generally accurate for standard calculations; verify edge cases |
| 4     | Reliable calculations; shows work for verification              |
| 5     | Provably accurate; all calculations traceable to source data    |

**Data Analysis Total: \_\_ / 20**

## Use Case 4: Administrative Automation

### Scoring Criteria

**Criterion 1: Document processing and extraction**
Can the tool extract key information from grant agreements, donor correspondence, or financial documents to populate your systems?

| Score | Description                                                           |
| ----- | --------------------------------------------------------------------- |
| 1     | No document processing capability                                     |
| 2     | Basic text extraction; significant cleanup required                   |
| 3     | Reliable extraction of structured information from standard documents |
| 4     | Handles varied document formats; produces structured output           |
| 5     | Integrates extracted data directly into your systems                  |

**Criterion 2: Meeting notes and action item tracking**
Can the tool transcribe, summarize, and extract action items from staff meetings, board meetings, or donor calls?

| Score | Description                                                                 |
| ----- | --------------------------------------------------------------------------- |
| 1     | No meeting assistance capability                                            |
| 2     | Transcription only; no summarization or extraction                          |
| 3     | Summarizes transcripts; extracts obvious action items                       |
| 4     | Produces concise summaries with categorized action items and owners         |
| 5     | Integrates with your project management system; creates tasks automatically |

**Criterion 3: Template generation and maintenance**
Can the tool help create and maintain organizational templates (grant report formats, board materials, staff policies) and update them when requirements change?

| Score | Description                                                           |
| ----- | --------------------------------------------------------------------- |
| 1     | No template capability beyond basic writing assistance                |
| 2     | Generates templates from scratch with heavy prompting                 |
| 3     | Produces usable templates from description of requirements            |
| 4     | Adapts templates to funder-specific requirements reliably             |
| 5     | Maintains a template library with version control and change tracking |

**Criterion 4: Workflow automation and integration**
Can the tool trigger actions in other systems (email a funder report, create a calendar reminder, log a donor interaction) based on conditions or events?

| Score | Description                                                    |

| 4     | Native integrations with nonprofit-relevant systems            |
| 5     | Purpose-built nonprofit automation workflows included          |

## Data Privacy and Compliance: Required Questions

This section is not scored - it's a pass/fail gate. If a vendor cannot answer these questions satisfactorily, do not adopt the tool regardless of feature scores.

**Question 1: Is your data used to train the AI model?**
The required answer: No, or opt-out is available with clear documentation of how to exercise it. If your donor data or grant files are used to train a shared model, that data could inform outputs provided to other organizations.

**Question 2: Is your organization's data isolated from other users' data?**
The required answer: Yes, with technical explanation of how isolation is achieved. Multi-tenant architectures where data is logically separated are generally acceptable; shared data pools are not.

**Question 3: GDPR and CCPA compliance?**
The required answer: Yes, with documentation of their data processing agreement (DPA) and privacy policy. If you have donors in the EU or California, the vendor must be GDPR/CCPA compliant.

**Question 4: Data retention policy?**
The required answer: Clear documentation of how long your data is retained, when it is deleted, and how you can request deletion. Retention periods should be reasonable (not indefinite) and consistent with your organizational data policies.

**Question 5: SOC 2 or equivalent security certification?**
The required answer: SOC 2 Type II or equivalent certification. For tools handling donor PII or grant financial data, security certification is a baseline requirement.

| **Total Year-1 Cost**                    | **$**\_\_\*\*\*\* |                               |

| Value of productivity gain               | $**\_\_**         | Hours - average staff cost    |

**Staff adoption note:** The most commonly underestimated cost in AI tool adoption is the staff time required to learn the tool, develop effective prompting patterns, and integrate it into existing workflows. A tool that saves 2 hours per week after full adoption may cost 20+ hours of staff time in the first three months. Factor this into your Year-1 cost estimate.

## Sample Completed Scorecard

To illustrate how the scorecard works in practice, here is a sample completed evaluation for a hypothetical general-purpose AI writing assistant (not based on any specific tool):

| Use Case                  | Score      | Max    | Notes                                                                          |
| ------------------------- | ---------- | ------ | ------------------------------------------------------------------------------ |
| Grant Writing Assistance  | 17         | 25     | Strong narrative quality; weak budget narrative; moderate compliance awareness |
| Donor Communication       | 19         | 25     | Good tone calibration; no CRM integration                                      |
| Data Analysis             | 10         | 20     | Limited to CSV analysis; no grant expenditure module                           |
| Administrative Automation | 12         | 20     | Good document extraction; no native integrations                               |
| **Total**                 | **58**     | **90** |                                                                                |
| Data Privacy Gate         | Pass       |        | SOC 2 Type II; data not used for training; opt-in required for DPA             |
| Year-1 Total Cost         | $4,800     |        | $3,600 subscription + $1,200 adoption time                                     |
| Year-1 Productivity Gain  | $6,000     |        | ~120 hours at $50/hr avg cost                                                  |
| **Net Year-1 Benefit**    | **$1,200** |        | Positive ROI, but modest                                                       |

**Interpretation:** This tool passes the data privacy gate and has a positive Year-1 ROI, but scores relatively low on data analysis and automation - the areas with the highest time-saving potential for a grants-heavy organization. Worth piloting for grant writing and donor communication; re-evaluate in 12 months as the tool's integration capabilities develop.
