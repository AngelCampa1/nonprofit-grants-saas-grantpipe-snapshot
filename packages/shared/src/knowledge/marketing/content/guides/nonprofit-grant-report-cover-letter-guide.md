A grant report cover letter is not the report. It is the guide to the report.

The funder should be able to read the letter and know what is attached, what period it covers, what changed, and who to contact. The letter should not add claims that the report cannot support.

For federal grants, performance reporting rules can sit in 2 CFR 200.329 and award terms. Foundation grants may use simpler forms, but the same discipline helps. Keep the letter clear, factual, and tied to source records.

## Start with the report facts

Open with the award name, grant number if one exists, reporting period, and attachment list. This sounds basic, but it prevents confusion when funders manage many reports.

Use the exact funder name and grant title from the agreement. If the grant has a program officer, address the letter to that person.

Do not start with a long story. The first paragraph should tell the funder what they are receiving.

## Summarize results without overselling

Use two or three sentences to summarize the work completed during the period. Name the program, population served, main outputs, and any required outcome measure.

Stay close to the report. If the report says 86 participants completed intake, the cover letter should not say the program transformed the community. If a result is early or partial, say that.

Good cover letter language is plain: "During this period, the program enrolled 86 participants, completed 74 service plans, and held 12 partner workshops."

## Explain material changes

If the work changed, explain it before the funder has to ask. Common changes include staff vacancies, delayed hiring, lower enrollment, budget shifts, vendor delays, or a revised timeline.

Keep the explanation short. Name the issue, the effect, and the fix. If formal approval was required, say whether approval was requested or received.

Do not bury a problem in cheerful language. A clear explanation builds more trust than a vague positive paragraph.

## Tie budget notes to the financial report

If the report includes a budget-to-actual schedule, the letter can point out major variances. It should not repeat every line.

For example, "Personnel spending was below budget because the case manager role was vacant for six weeks. The position was filled on May 12, and the revised staffing plan is reflected in the attached budget note."

Finance should review this section before it goes out. The wording should match the numbers.

## Name the attachments

List the attachments in the order the funder should read them. This may include the narrative report, financial report, outcome table, budget variance note, reimbursement request, photos if allowed, and source documentation.

Do not attach extra files because they seem helpful. Send what the funder asked for and what supports the report.

If private client details appear in any support, review privacy rules before sending. Aggregate results are usually safer than individual stories.

## Match the letter to the funder portal

Some funders ask for a PDF upload. Others ask staff to paste notes into a portal field. The cover letter should still match the submission method.

If the portal has a short text box, use the first paragraph of the letter as the summary and attach the full report package. If the portal sends email notices to the funder, make sure the file names are clear.

Save a copy of the final portal text. Otherwise the organization may keep the report but lose the message that explained it.

## Use a simple close

Close with a contact person and next step. If the report requires approval, name the signer. If the funder may have questions, give the right email or phone number.

Avoid dramatic thanks or broad claims. A simple thank you is fine. The funder relationship is supported by accurate work and clean reporting.

## Suggested structure

Use this order:

- greeting
- award and reporting period
- attached files
- short results summary
- material changes or variances
- contact person
- signer

This structure works for most funder reports because it respects the reader's time.

## Review before sending

Before sending, compare the letter to the report. Check names, dates, amounts, outputs, outcomes, and attachments. Then ask finance to review financial language and program staff to review service language.

If the report was prepared in GrantPipe, use the grant record, report calendar, budget notes, and evidence files as the source for the cover letter. That keeps the letter connected to the same facts the team will use later.

Save the sent letter with the final report package. A year later, the cover letter should still explain what the funder received and why.
