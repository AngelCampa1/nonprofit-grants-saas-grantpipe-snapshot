# Grant compliance file index template guide

A grant file should not depend on one person's memory. It should have a clear index that tells staff where each record lives, who owns it, and whether it is ready for review. This matters for deadlines, audit evidence, restricted funds, and reporting.

The index does not need to be fancy. It needs to be complete and easy to keep current.

## Start with the award setup section

The first section should prove what the award is. Include the award letter, agreement, amendments, approved budget, grant period, payment terms, reporting schedule, contact list, and special conditions.

Add fields for:

- Grant name
- Funder
- Award number
- Assistance Listing number, if federal
- Start and end date
- Budget amount
- Payment method
- Internal owner
- Finance reviewer
- Program owner

This section helps staff answer basic questions without searching email. It also helps finance know whether a grant creates restricted funds, reimbursable revenue, or conditional revenue that needs review.

## Add a deadline section

Deadlines belong in the index because missed reports create risk. List every financial report, program report, reimbursement request, board report, closeout item, and renewal date.

Each deadline should have an owner, reviewer, source files, and submission proof. Submission proof may be an email confirmation, portal receipt, or saved copy of the submitted report.

GrantPipe can help teams track grant deadlines, reporting work, donor CRM context, restricted funds, grant compliance tasks, and audit evidence in one place. The index still matters because it names the records that should exist.

## Add a budget and spending section

The budget section should show how approved budget lines map to ledger codes. This prevents confusion when finance reports use different labels than the funder budget.

Include:

- Approved budget
- Budget amendments
- Ledger code map
- Budget to actual reports
- Expense detail
- Match or cost share support, if any
- Notes for shared costs

For federal grants, include the support that shows costs are allowable and allocable. If a shared cost allocation is used, link to the method and review notes.

## Add a reporting section

Every submitted report should have a record set. Save the submitted report, source schedule, ledger tie-out, reviewer approval, and submission proof.

If the report includes program outcomes, keep the source data and program signoff. If it includes spending, keep the finance tie-out. If it includes restricted fund balance, keep the reconciliation.

The index should show whether reports were submitted on time. It should also show whether a report was revised after submission.

## Add an expense evidence section

Expense support should be easy to sample. The index can point to folders by month, vendor, budget line, or transaction ID. Choose a structure staff can use all year.

Each expense file should include the invoice or receipt, approval, payment proof, grant coding, and any procurement support required by policy or award terms.

For payroll, include pay period records, time records, allocation support, and approval. Payroll evidence often lives outside the grant file, so the index should link to the exact location.

## Add a restricted fund section

If the grant creates a donor or grant restriction, the file should include the restriction terms, cash receipts, receivables, qualifying expenses, releases, and ending balance support.

This section should tie to the restricted fund reconciliation or net asset rollforward. Do not treat cash balance as the full answer unless finance has reviewed the accounting.

Restricted funds can affect board reporting, audit support, and grant reports. Keeping them in the index helps the team avoid separate versions of the truth.

## Add a correspondence section

Save funder emails and portal messages that change the record. This includes budget approvals, deadline extensions, report questions, amendment notes, monitoring requests, and closeout acceptance.

Do not save every routine email. Save messages that explain a decision, requirement, or deadline.

## Add a closeout and retention section

Closeout should have its own part of the index. Include final reports, final reimbursement, remaining balance review, equipment records, funder acceptance, and record retention date.

For federal awards, 2 CFR 200 includes record retention rules. The exact date can depend on final submission and other factors. Ask your auditor or counsel how to set the retention date for a specific award.

## Review the index during normal work

The file index should be checked at award setup, monthly close, each report deadline, each amendment, and closeout. If a file is missing, assign an owner and due date.

A good index makes grant management less fragile. It turns the grant file into a shared record, not a hidden folder. When the audit request arrives, staff can answer with evidence instead of searching through inboxes.
