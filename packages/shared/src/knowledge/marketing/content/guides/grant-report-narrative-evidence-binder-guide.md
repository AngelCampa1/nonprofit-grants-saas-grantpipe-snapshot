# Grant report narrative evidence binder guide

A grant report tells the funder what happened. The evidence binder shows how you know.

Without a binder, report writing often depends on memory, email searches, and last-minute requests to finance or program staff. That makes the narrative harder to trust. It also makes audit evidence harder to find later.

Build the binder while the report is being prepared. Use it again when the funder asks a question, when leadership reviews the grant, or when an auditor requests support.

## Start with the report requirements

Read the award agreement and report instructions before gathering files. Each funder may ask for different proof.

List:

- Report due date
- Reporting period
- Required narrative questions
- Required outcome measures
- Required financial report
- Required attachments
- Submission method
- Retention rule
- Reviewer

For federal awards, Grants.gov describes reporting as part of the post-award process. 2 CFR 200.329 covers performance reporting. 2 CFR 200.302 covers financial management records. 2 CFR 200.334 covers record retention. Private funders may have simpler terms, but the binder should still support what was submitted.

## Create a simple folder structure

Do not make a folder tree so complex that staff avoid it. Use clear sections:

- 01 Award and budget
- 02 Report instructions
- 03 Program records
- 04 Outcome support
- 05 Financial support
- 06 Match support
- 07 Draft and review notes
- 08 Final report and submission proof

Use dates in file names. Add the grant name and reporting period when helpful.

Example: `2026-06-30 youth-program q2 attendance-summary.pdf`

Avoid vague names like `final final report.pdf`. Vague names make later review slow.

## Tie every claim to a source

The narrative should not make claims that the binder cannot support. If the report says 240 people attended, the binder should include the attendance record or summary. If it says spending was delayed because hiring took longer, the binder should include the budget note or staffing record that supports the statement.

Create a claim table:

- Narrative claim
- Source file
- Owner
- Date reviewed
- Notes

This does not need to be fancy. A simple table can save hours later.

## Include program evidence

Program evidence shows what work happened.

Common records include:

- Attendance logs
- Case counts
- Workshop rosters
- Service records
- Partner confirmations
- Survey summaries
- Outcome dashboards
- Photos with permission
- Curriculum or agenda files

Do not store sensitive participant details unless the funder requires it and your privacy policy allows it. Use summaries when possible.

Program staff should review the evidence before the report is submitted. They know whether a number is real, incomplete, or missing context.

## Include financial evidence

A narrative report often includes financial statements, even when the report form looks program focused. Spending pace can explain program activity. Restricted funds can affect what the nonprofit can claim.

Ask finance for:

- Approved budget
- Budget to actual report
- General ledger detail
- Payroll allocation support
- Invoice support
- Reimbursement request status
- Restricted fund balance
- Match records if required

The binder should not replace the accounting system. It should point to the records used for the report. If the report number changes after review, save the final support.

## Save review and approval proof

Report review matters. Keep evidence that the right people reviewed the report before submission.

Save:

- Program review note
- Finance review note
- Executive approval if required
- Board approval if required
- Funder portal confirmation
- Email submission receipt

This helps when a funder asks who approved a number or when staff change roles.

## Use the binder after submission

After submission, mark the report complete and save the final version. Then add any funder response.

If the funder asks for a correction, save:

- Original submission
- Funder question
- Internal review
- Corrected file
- Final confirmation

GrantPipe can help teams manage grant compliance work by connecting deadlines, documents, restricted funds, report status, and audit evidence. The binder should make the final report easier to defend, not just easier to write.

## Keep retention visible

Record retention rules depend on the funder and award terms. Federal awards have specific record retention rules under 2 CFR 200.334. Some funders may require longer retention. Some records may also be subject to state, audit, privacy, or contract rules.

Do not treat this guide as legal or accounting advice. Use it as an operating checklist, then follow the award terms and your policy.

A good binder keeps the nonprofit honest. It lets the report say only what the records support. That is better for the funder, the board, and the next staff person who has to answer a question.
