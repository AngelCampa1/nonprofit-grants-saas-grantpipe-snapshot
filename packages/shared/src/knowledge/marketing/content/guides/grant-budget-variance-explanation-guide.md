A variance explanation is not an excuse. It is a record of what changed.

Good explanations help funders, auditors, and leaders see whether spending still fits the award.

## Start with the numbers

Show the approved budget, actual spending, and variance. Use dollars and percent.

Do not write the explanation before the numbers are tied to the ledger. A strong narrative cannot fix weak math.

## Name the cause

Common causes include delayed hiring, higher supply costs, lower participant volume, late contracts, timing differences, and approved budget shifts.

Use plain language. "Personnel is underspent because the case manager role was vacant for 6 weeks" is better than a vague operations note.

## Check approval rules

Some budget changes need prior written approval. Some do not. The award terms decide.

If approval was needed, attach the request and approval. If approval was not needed, note the rule or threshold that allowed the change.

Use the [grant budget amendment process guide](/resources/guides/grant-budget-amendment-process) when the variance requires a formal change.

## Explain program impact

The funder needs to know whether the work changed. Did the variance affect service volume, staffing, timeline, match, or outcomes?

If there was no program impact, say that clearly and explain why.

## Add the next action

Every variance should end with a decision:

- monitor next month
- move costs after approval
- submit budget revision
- adjust hiring plan
- explain timing difference in the next report

The decision should have an owner and date.

## Variance explanation structure

Use the same structure each month. It keeps the report readable and makes review faster.

| Section        | What to write                                      |
| -------------- | -------------------------------------------------- |
| Amount         | State the budget, actual, and variance.            |
| Cause          | Name the plain reason for the difference.          |
| Award impact   | Say whether approval, match, or scope is affected. |
| Program impact | Explain service, staffing, or timeline impact.     |
| Action         | Name the next step, owner, and date.               |

Example: "Personnel is $8,200 under budget because the navigator role was vacant from May 6 to June 14. The vacancy delayed 12 intake appointments. No budget revision is needed yet because the team expects to fill the role in July. The grants manager will review this line again before the August report."

That is better than "spending variance due to staffing changes." The funder can see the reason and the plan.

## Review thresholds

The award may set a formal rebudget threshold. Even when it does not, the organization should set an internal threshold for review.

Common triggers include:

- a line item variance over the internal threshold
- spending outside the approved category
- persistent underspending
- spending that may exceed the award budget
- a change that affects match
- a change that affects promised service levels

Do not wait for a report deadline to notice a major variance. Monthly review gives staff time to ask for approval before costs move too far.

## Tie variance notes to the ledger

The variance note should point back to the ledger report used. Save the report date and any filters. If the variance depends on a journal entry, save the entry number.

For shared costs, keep the allocation support. A variance caused by allocation changes needs more explanation than a simple invoice timing issue.

## Source-backed caveats

2 CFR 200.308 covers revision of budget and program plans. Federal awards may require prior approval for certain changes. The award terms can be stricter.

2 CFR 200.403 and 200.404 still apply when a budget line has funds available. A cost can be under budget and still be unallowable or unreasonable.

For private foundation grants, the federal rules may not apply. The same discipline still helps. It gives the funder a clear explanation and helps the nonprofit decide whether a formal amendment is needed.

## Board and leadership use

Budget variance notes should also help leadership. The executive director does not need every invoice detail. They do need to know whether the variance affects service delivery, cash timing, or funder trust.

For board packets, group variances by decision need:

- watch only
- staff action underway
- funder approval needed
- board awareness needed

This keeps the board out of small accounting noise while still surfacing real risk. A $2,000 supply variance may not matter. A persistent personnel underspend may matter because it can change program output, match, and renewal odds.

The same variance note can serve both audiences if it is written plainly. Start with the number. Name the cause. Say what happens next.
