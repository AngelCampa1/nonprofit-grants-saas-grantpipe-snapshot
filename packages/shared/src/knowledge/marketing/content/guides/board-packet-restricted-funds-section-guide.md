A board packet can show a healthy cash balance and still hide a problem.

The problem is restriction. Some dollars can be used only for a stated purpose, program, or time period. If the board sees only total cash, it may think the organization has more flexible money than it does.

That is why the board packet needs a restricted funds section. It does not need to be long. It does need to show what money is limited, how balances changed, and where board attention is needed.

Use this guide with [restricted fund accounting basics](/resources/guides/restricted-fund-accounting-basics) and [donor-restricted versus board-designated funds](/resources/guides/donor-restricted-vs-board-designated-funds).

## Separate donor restrictions from board designations

Start with clean labels.

Donor-restricted funds come from a donor or funder limit. A grant for one program is restricted. A gift for a building fund is restricted. A time-limited pledge may be restricted until the right period.

Board-designated funds are different. The board sets them aside, but the board can usually change that choice.

Do not mix the two in one line. A board-designated reserve is not the same as a donor-restricted grant.

## Show the roll-forward

The restricted funds section should show how balances moved.

Use this simple roll-forward:

- beginning restricted balance
- new restricted gifts and grants
- releases from restriction
- restricted spending
- ending restricted balance

Add notes for the largest changes. If one grant caused most of the increase, name it. If a large release happened, explain which purpose or time limit was met.

## List large restricted balances

Do not list every small fund on the first page. Show the largest balances and any balance with risk.

For each large balance, show:

- fund or grant name
- purpose
- current balance
- expected use period
- next report or review date
- concern, if any

This helps the board see whether money is sitting for a good reason or because spending is delayed.

## Add a grant link

Many restricted balances come from grants. The board packet should connect the restricted fund view to the grant view.

For active grants, show:

- award amount
- amount spent
- amount remaining
- report due date
- receivable amount
- spending pace

Use the [board grant reporting dashboard](/resources/guides/nonprofit-board-grant-reporting-dashboard) for the grant-level view. The restricted funds section should not repeat every detail. It should make the connection clear.

## Explain releases in plain words

Board members may not use accounting terms every day. Explain releases from restriction in plain language.

Example:

"The $85,000 release from restriction means program costs were incurred for the purpose allowed by the grant. The funds moved from restricted to without donor restrictions in the statement of activities."

That sentence helps board members connect the accounting entry to real work.

## Name risks and actions

The restricted funds section should include a small risk box.

Examples:

- "Youth program grant is 35% behind spending plan."
- "Building fund balance is restricted and cannot be used for payroll."
- "Grant receivable is 74 days old."
- "Funder report is due before the next board meeting."
- "Board approval needed for budget change."

Do not make board members infer risk from numbers alone. Say what needs care.

## Keep backup detail nearby

The main board packet should stay short. Keep the full schedule as backup for the finance committee and audit file.

Backup can include:

- fund-by-fund ledger
- award letters
- donor restriction letters
- release calculations
- grant budgets
- report copies
- reconciliation to accounting records

The [restricted fund month-end close checklist](/resources/guides/restricted-fund-month-end-close-checklist) can help finance keep that support current.

## Ask better board questions

A good restricted funds section helps the board ask useful questions:

- Which funds are restricted by purpose?
- Which restrictions will end soon?
- Which balances are not spending as planned?
- Which restricted funds affect cash?
- Which balances need board approval or policy action?

Those questions are better than "Why is cash up?" or "Can we use this money?"

## Simple section order

Use this order in the board packet:

1. Restricted funds summary.
2. Largest restricted balances.
3. Releases this period.
4. Grant-linked restrictions.
5. Risk and action notes.
6. Backup file location.

That gives the board the oversight view without turning the packet into an audit binder.
