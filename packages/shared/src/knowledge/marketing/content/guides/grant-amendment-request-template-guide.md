# Grant amendment request template guide

Grant work changes. Staff leave. Costs move. Timelines slip. A funder may allow changes, but the nonprofit should not assume it can make them without approval.

Use an amendment request when the award terms require funder approval for a budget change, scope change, period change, or other material change.

## Check whether approval is needed

Read the award terms first. Do not send an amendment request for every small change, and do not skip approval for a change the funder controls.

Look for rules about:

- Budget transfers
- Scope changes
- Key staff changes
- No-cost extensions
- Equipment purchases
- Subawards
- Carryforward
- Change in effort
- Change in deliverables

For federal awards, 2 CFR 200.308 covers revision of budget and program plans. Section 200.309 covers period of performance. Award terms may add more rules.

If the rule is unclear, ask the funder before acting. A short question before the change is easier to manage than a late correction after costs are posted or work has changed.

## Use a clear request header

Start the request with facts the funder can verify.

Include:

- Organization name
- Grant name
- Award number if any
- Funder contact
- Current grant period
- Current award amount
- Request type
- Submission date
- Organization contact

Make the request easy to route. Funders may handle budget changes, scope changes, and extensions through different staff or portals.

## State the requested change

Use one plain paragraph.

Example:

"We request approval to move $8,000 from travel to contract services. The total award amount will not change."

For a time extension:

"We request a three month no-cost extension from September 30, 2026, to December 31, 2026."

Avoid vague language. The funder should know exactly what approval is being requested.

## Explain the reason

Give the reason without blame or drama.

Good reasons may include:

- Hiring delay
- Vendor delay
- Lower travel need
- Higher participant demand
- Program schedule change
- Funder approved scope update
- Weather or facility delay
- Data collection timing

Tie the reason to the funded work. Do not use the request to rewrite the full proposal.

## Show budget effects

Finance should prepare the budget section.

Show:

- Current approved budget
- Requested change by line
- Revised budget
- Amount already spent
- Amount remaining
- Match effect
- Indirect cost effect

If the change affects reimbursement or cash flow, say so. If the change does not affect the total award, say that too.

## Show program effects

Program staff should explain how the change affects service and outcomes.

Cover:

- Work completed
- Work still planned
- Deliverables affected
- Outcome targets affected
- Service dates
- Staff or partner roles

If the change does not reduce service, state that. If it does reduce or change service, explain what the funder should expect.

## Attach support

Support depends on the request.

Useful support may include:

- Revised budget
- Budget to actual report
- Timeline
- Vendor quote
- Program schedule
- Staffing note
- Board approval if required
- Partner letter

Keep attachments focused. More pages do not make a weak request stronger.

## Use a simple template

A practical request can follow this order:

1. Grant and organization facts
2. Requested change
3. Reason for change
4. Budget effect
5. Program effect
6. Timeline
7. Attachments
8. Contact for questions

GrantPipe can help keep the amendment request tied to the original award, current budget, report dates, and approval record. That link matters when finance reviews the grant later.

## Wait for approval

Do not act on a change that needs approval until the funder approves it in writing. Save the approval with the grant file.

If the funder denies the request, save that response too. Then update the budget, report plan, and staff tasks so the team follows the current award terms.

An amendment request is not a failure. It is a control that keeps the grant record honest when real work changes.

After approval, update the working records. Revise the budget, calendar, report matrix, task owner, and grant file. Tell finance and program staff what changed, what stayed the same, and which date or dollar amount now controls the work.
