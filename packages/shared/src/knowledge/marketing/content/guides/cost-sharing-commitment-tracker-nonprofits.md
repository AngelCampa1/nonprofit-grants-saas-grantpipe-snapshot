# Cost sharing commitment tracker for nonprofits

Cost sharing sounds simple during proposal work. Staff name a match source, add it to the budget, and move on. The hard part comes later, when the nonprofit must prove the match happened and was allowed.

A cost sharing tracker keeps each promise visible from proposal to closeout.

## Start before the proposal is sent

Do not wait until award to track match. If the proposal includes cost sharing, create the tracker before submission.

Record:

- Grant name
- Funder
- Required match amount
- Match percentage if any
- Match source
- Cash or in-kind
- Owner
- Evidence needed
- Timing
- Restrictions

This helps finance review the promise before the nonprofit is bound to it.

## Know the funder rule

For federal awards, 2 CFR 200.306 covers cost sharing or matching. It describes standards such as verifiability, allowability, and not using the same contribution for another federal award unless allowed.

Other funders may use their own rules. Some allow volunteer time. Some allow donated space. Some require cash match. Some do not allow match from certain sources.

Write the funder rule in plain language in the tracker. Staff should not have to reread the award each time they add support.

## Build the tracker columns

Use columns that make review easy.

Recommended columns:

- Commitment ID
- Grant
- Match source
- Type
- Amount promised
- Amount documented
- Remaining amount
- Valuation method
- Evidence file
- Restriction
- Date received or used
- Owner
- Reviewed by
- Reported date
- Notes

Add a status column with values like planned, received, documented, reported, rejected, or replaced.

## Separate cash match from in-kind match

Cash match is money. It may come from unrestricted funds, another allowed grant, a donation, or a partner payment.

In-kind match is non-cash support. It may include donated services, supplies, space, or volunteer time if allowed.

Each type needs different proof. Cash match often ties to ledger detail and bank records. In-kind match needs a fair value basis and proof that the support was used for the grant project.

## Check restrictions

Not all money can be used as match. A restricted donation may be limited to another purpose. Another grant may ban use as match. A federal source may not be allowed to match another federal award unless the rules permit it.

Before counting a source, ask:

- Who provided it?
- What restriction came with it?
- Does the funder allow this source?
- Has it been counted anywhere else?
- Can we support the amount?

If any answer is unclear, hold the source out until finance reviews it.

## Support the value

The tracker should show how each amount was valued.

Support may include:

- General ledger detail
- Donor record
- Partner letter
- Volunteer log
- Payroll record
- Invoice
- Lease or market rate support
- Signed certification

For charitable contributions, IRS substantiation rules may also matter for donor records. That is separate from grant match support, but the records should not conflict.

## Review during each report period

Match can fall behind just like spending.

At each report period, review:

- Amount promised
- Amount documented
- Amount still needed
- Evidence gaps
- Sources no longer available
- Replacement sources
- Reported amounts

GrantPipe can help keep match commitments tied to grant budgets, restricted funds, reports, and documents. That makes it easier to see whether the match is ready before the report is due.

## Avoid common errors

Watch for these issues:

- Counting the same match twice
- Counting unsupported volunteer time
- Using restricted funds for the wrong purpose
- Missing valuation notes
- Reporting match before evidence is saved
- Counting costs outside the grant period
- Forgetting partner documentation

Each issue is easier to fix early than at closeout.

## Close the commitment

At closeout, the tracker should show the final match amount, evidence, reported date, and any funder acceptance. Save the tracker with the grant closeout file.

If the nonprofit did not meet the required match, escalate before the final report. The funder may need notice, a budget change, or another action. Do not hide the gap in the final package.
