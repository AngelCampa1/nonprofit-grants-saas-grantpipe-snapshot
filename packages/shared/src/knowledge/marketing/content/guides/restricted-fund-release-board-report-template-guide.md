Restricted fund releases can confuse board members. The word "release" can sound like cash arrived, cash left, or a donor gave permission. In accounting, it means the nonprofit has met a donor restriction and moved the amount out of net assets with donor restrictions.

A good board report makes that plain. It shows what changed, why it changed, and what risk remains.

This guide gives a template structure for monthly or quarterly board packets. It is not a substitute for your accounting policy or auditor review.

## Start with one summary table

Use one board table for the whole restricted fund picture. The table should fit on one page when possible.

Recommended columns:

- Fund or grant
- Restriction purpose
- Beginning restricted balance
- New restricted gifts or grants
- Releases this period
- Ending restricted balance
- Evidence status
- Risk or note

The board does not need every transaction. It does need to know whether the release is supported. Add a clear evidence status such as complete, pending review, missing support, or needs approval.

GrantPipe can help connect restricted funds, reporting deadlines, donor CRM context, and audit evidence. The board report still needs human judgment, but the support should not be scattered across inboxes and spreadsheets.

## Explain the release basis

Each material release should have a short reason. Use plain words:

- Program costs met the purpose restriction.
- The time restriction ended on June 30.
- The campaign asset was placed in service.
- The grant condition was met and reviewed.
- The donor approved a narrowed use in writing.

Avoid vague notes such as "per finance" or "per accounting." Name the fact that supports the release.

If both time and purpose restrictions apply, say both were reviewed. If only part of the restriction was met, show a partial release.

## Tie releases to support

The board packet can stay short, but the finance file must be complete. Keep the donor agreement, grant terms, expense detail, payroll allocation, program record, approval, and journal entry.

If the release depends on spending, tie it to qualifying costs. If it depends on time, tie it to the date. If it depends on a milestone, save proof that the milestone happened.

This matters during audit. The board report should not become the only support. It is a summary of a supported file.

## Show remaining restrictions

The ending restricted balance is often the most important board number. It tells leaders which dollars still have limits.

Show large remaining balances and what must happen before release. For example: "Youth program grant remains restricted until eligible summer payroll is incurred" is useful. "Restricted until used" is too vague.

Also show deadlines. If a restricted fund must be spent by a date, the board should see that date. If a grant report is due soon, show it next to the balance.

## Add cash context

Restricted net assets and restricted cash are not always the same. A nonprofit may have a pledge receivable with donor restrictions. It may also hold restricted cash that has not been spent.

Add a short cash note when the difference matters. For example: "The $80,000 restricted balance includes $35,000 in pledges not yet collected." Or: "Cash is on hand, but it remains restricted until approved program costs are incurred."

This helps the board avoid treating restricted dollars as general operating cash.

## Flag risks without drama

Board members need clear risk, not a wall of detail. Use a risk column for:

- Missing release support
- Negative restricted fund balance
- Late funder report
- Pledge collection concern
- Grant ending soon with unspent restricted balance
- Expenses posted outside the restriction
- Release waiting on reviewer approval

Assign each risk an owner and next step. "Finance will review May payroll support by July 8" is better than "pending."

## Use consistent labels

Use the same fund names each month. Changing labels makes trends hard to follow. If the fund name changes, note the change once.

Do not use internal shorthand that only finance understands. Board members should not need to decode fund codes. Put the fund code in a detail appendix if needed.

## Close with decisions

Some board reports need a vote. Others only need review. Make that clear. If approval is needed, state the action in one line. If no action is needed, say that the report is for oversight.

Do not bury a decision in the notes. If the board must approve a release policy, write-off, donor modification, or budget action, give it a separate line.

## Common mistakes

Common mistakes include showing releases without ending balances, showing restricted balances without deadlines, using cash as a proxy for restricted net assets, and omitting evidence status.

Another mistake is giving the board too much ledger detail and too little meaning. A long transaction list can still hide the important question: can the money be used, and what proof supports that answer?

A board report should make restricted funds easier to govern. It should help leaders see releases, remaining limits, deadlines, audit evidence, and reporting risks before they become surprises.
