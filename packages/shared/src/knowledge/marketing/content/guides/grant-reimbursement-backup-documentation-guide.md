# Grant reimbursement backup documentation guide

A reimbursement request asks a funder to repay costs the nonprofit already recorded or paid. The request is only as strong as the backup behind it.

Good backup makes the request easier to review. Weak backup can delay cash, create extra staff work, or raise audit questions later.

## Start with the funder rules

Read the award terms before building the package. Do not assume every funder wants the same proof.

Check:

- Reimbursement form
- Eligible cost period
- Required signatures
- Invoice rules
- Proof of payment rules
- Payroll support rules
- Match support rules
- Submission method
- Deadline
- Contact person

For federal awards, financial records should identify the award and support source and use of funds. Payment rules and cost principles also matter. The award may add more specific instructions.

## Build a request summary

Start the package with a summary that matches the funder form.

Include:

- Grant name
- Funder
- Request number
- Reporting period
- Budget line
- Amount requested
- Cumulative amount requested
- Remaining budget
- Prepared by
- Reviewed by
- Submission date

The summary should tie to the general ledger detail. If the summary says $4,200 for supplies, the detail should show the costs that make up that amount.

## Include general ledger detail

The general ledger detail is the bridge between the accounting system and the request.

Review it for:

- Correct grant code
- Correct period
- Vendor name
- Transaction date
- Clear description
- Amount
- Budget line
- Duplicate costs
- Costs outside the grant period
- Costs posted to the wrong fund

Do not send messy detail and expect the funder to sort it out. Clean the report first.

## Add invoice and receipt support

For non-payroll costs, save the source record.

Common records:

- Vendor invoice
- Receipt
- Contract
- Purchase order
- Packing slip if needed
- Approval record
- Proof of payment if required

The invoice should show what was bought, who sold it, the date, and the amount. If the description is vague, add a short note that explains how the cost supports the grant.

## Support payroll costs

Payroll needs special care because it is often large and recurring.

Support may include:

- Payroll register
- Time and effort record
- Allocation worksheet
- Job description
- Pay period dates
- Fringe calculation
- Supervisor approval

For federal awards, 2 CFR 200.430 covers standards for compensation and personal services. Keep the support tied to work performed, not just budgeted time.

## Document shared costs

Some costs support more than one program or grant. Do not charge the full cost to one grant unless the grant received the full benefit.

For shared costs, include:

- Total cost
- Allocation basis
- Calculation
- Grants or funds charged
- Approval
- Backup record

A reasonable basis may be square footage, staff time, participant count, or another method that fits the cost. Use the same method consistently unless there is a documented reason to change it.

## Review match records

If the reimbursement period includes match or cost share, include match support when the funder requires it.

Match support may include:

- Donation record
- Volunteer log
- Payroll record
- In-kind valuation
- Partner letter
- General ledger detail

Check that match is not counted twice and is allowed by the award.

## Run a pre-submission review

Before sending the request, ask:

- Are all costs in the grant period?
- Are all costs allowed?
- Does each amount tie to the ledger?
- Is proof of payment included if required?
- Are payroll records complete?
- Are shared costs allocated?
- Is the request signed?
- Is the package saved?

GrantPipe can help connect reimbursement requests, expense records, documents, and report dates so the review is tied to the grant file instead of scattered across folders.

## Save the final package

Save the exact package that was submitted. Also save submission proof, funder questions, revised files, approval notice, and payment record.

Label the file by grant, period, and request number. A clear file name helps when finance needs to answer a funder question months later.

The goal is simple: every dollar requested should be easy to trace from budget to cost to backup to payment.
