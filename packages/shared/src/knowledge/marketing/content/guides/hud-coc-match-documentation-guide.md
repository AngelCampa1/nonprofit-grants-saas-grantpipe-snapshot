# HUD CoC match documentation guide

HUD CoC match is easy to under-document. A commitment letter may prove that a partner planned to help, but it does not prove the match happened. A donated service may have value, but the file still has to show the service, date, basis for value, and link to the funded activity.

HUD's CoC match guidance says recipients and subrecipients must match at least 25 percent of grant funds expended, except leasing funds. Match can be cash or in-kind. The file should make that calculation simple.

## Start with the match register

Build a register before the award starts. For each match source, list the source name, type, amount, date committed, eligible activity, valuation method, support received, and staff owner. Add one column for "used in report" so finance can see which match has already been counted.

Do not wait until closeout. Match gets messy when teams rebuild it from old emails. A live register lets you compare match received to CoC costs while there is still time to fix gaps.

## Separate cash from in-kind

Cash match needs written commitment from the source and records showing the cash was received and used for eligible costs. Keep the commitment letter, bank or ledger proof, and the expense support. If the source is another grant, confirm it is not federal money unless the source law allows it to be used as match.

In-kind match needs proof that the goods or services were actually provided. For donated services, keep a service agreement, time records, service dates, rate support, and a short note showing why the service would be eligible under the CoC award. For donated goods, keep a receipt or valuation record.

HUD's in-kind documentation guidance asks recipients and subrecipients to document that the donation was provided and record the value. The valuation should be reasonable. A volunteer hour should use a supportable rate for that type of work, not a guess.

## Check eligible and ineligible sources

Not every helpful contribution can count as match. The match must support eligible CoC activities. It must also be from an eligible source. HUD guidance warns that if the source or amount changes during the contract year, the recipient or subrecipient must document the actual source and amount.

Review source changes as they happen. If a promised cash match drops, replace it with a documented source before the gap grows. If a partner changes the service it provides, confirm the new service still ties to an eligible activity.

## Tie match to spending

Match is based on grant funds expended. That means the match schedule should sit next to your federal spending report. Each reporting period, compare CoC expenditures to match counted. If leasing is excluded from the match base, document the exclusion so reviewers can follow the math.

Use the [grant documentation checklist](/resources/guides/grant-documentation-checklist-audit-ready) to keep the source support complete. Match records should be just as easy to review as federal cost records.

## Avoid double counting

A donated service can only be counted once. A cash contribution used as match for one award should not also be used as match for another award. Add a "counted toward" field to the register. Include the award name, reporting period, and amount counted.

Double counting often happens when programs share partners. For example, a clinic may provide in-kind services to more than one housing program. The match file should show which portion supported the CoC award and which portion supported other work.

## Keep subrecipient files tight

If your nonprofit is a subrecipient, the city, county, or CoC pass-through entity may ask for match support before reimbursing costs. Ask for the required format early. Some pass-through entities want a specific match certification form. Others accept a register plus source files.

If your nonprofit passes funds to another subrecipient, your monitoring work should include match. The [subrecipient monitoring guide](/resources/guides/subrecipient-monitoring-requirements-uniform-guidance) explains how to review reports, costs, and source records without turning monitoring into a paper chase.

## Review before closeout

Before final reporting, check four things. First, the match base excludes costs HUD says do not require match. Second, the match counted is at least the required amount. Third, every source is eligible and documented. Fourth, no match was counted twice.

Keep the final match register with the closeout file. Under federal record rules, financial records and support must be retained after final reporting. See the [federal award closeout retention guide](/resources/guides/federal-award-closeout-document-retention-guide) for a broader file plan.
