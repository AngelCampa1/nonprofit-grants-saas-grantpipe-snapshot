# FEMA Nonprofit Security Grant file guide

FEMA's Nonprofit Security Grant Program can fund cameras, access controls, lighting, bollards, training, planning, and other security-related work. The file needs to show more than the fact that the nonprofit bought security equipment. It should show the approved project, EHP status, procurement process, equipment record, reimbursement support, and closeout.

Use this guide with the [equipment inventory guide](/resources/guides/federal-grant-equipment-tagging-inventory-guide) and [procurement file checklist](/resources/guides/2-cfr-200-procurement-file-checklist).

## Start with the approved project

Keep the award notice, state administrative agency instructions, investment justification, approved budget, and any conditions in one folder. The investment justification matters because it explains the security risk and approved work. Costs should tie back to that approved project.

If the project changes, keep the approval. Do not swap security items just because a vendor suggests a different package. The grant file should show that the final purchase still fits the approved scope.

## Clear EHP before work starts

FEMA Environmental and Historic Preservation review can apply to projects that involve installation, construction, ground disturbance, exterior work, or changes to buildings. Work should not start until required EHP review is complete.

Keep EHP submission records, photos, scope details, FEMA response, and clearance in the file. If FEMA says no EHP review is needed for an item, keep that note too. During monitoring, "we thought it was minor" is not a substitute for clearance.

## Keep procurement support

NSGP purchases still need proper procurement. Keep quotes, bids, vendor selection notes, conflict checks, contract or purchase order, invoice, and approval. If only one vendor could perform the work, keep the written sole source basis and approval.

Procurement records should be dated before the purchase. Rebuilding quotes after the fact is weak support and may fail review.

## Match purchases to the investment justification

Before placing an order, compare each item to the approved investment justification and budget. The file should show why the item was part of the security project. If the nonprofit buys a different model, adds an accessory, or changes the installation location, keep the reason and approval.

This check prevents a common problem. A vendor quote may include useful items that were not in the approved project. Useful is not the same as approved. The grant file should show both need and approval.

## Track equipment

Equipment records should include item description, serial number if applicable, purchase date, cost, funding source, location, condition, and person responsible. For fixed security equipment, record the building and location. For portable equipment, record where it is stored and how it is checked.

2 CFR 200.313 covers equipment management for federal awards. Even if an item is below your capitalization threshold, it may still need tracking because it is sensitive or grant-funded.

## Keep installation proof

For installed items, keep work orders, completion notes, photos if safe to store, and acceptance approval. If photos expose sensitive security layouts, store them in a limited-access folder and reference that location in the grant file.

The point is to prove the work was completed without making the security plan easier to misuse. Use a short completion memo when detailed images should not be widely shared.

## Prepare reimbursement packets

Many nonprofits receive NSGP funds through a state administrative agency. Follow that agency's reimbursement format. A strong packet includes invoice, proof of payment if required, procurement support, EHP clearance, approval, and budget line tieout.

If the reimbursement covers installation, include proof that installation happened after EHP clearance and within the project period.

## Separate security-sensitive details

Grant reviewers need enough information to confirm the cost. They do not always need a detailed map of every camera angle or alarm code. Store security-sensitive details under limited access. In the reimbursement packet, include the minimum support needed to prove the item and cost.

This protects the nonprofit while still keeping the grant file complete.

## Close and retain records

At closeout, confirm all purchases are complete, equipment is recorded, reimbursements match the ledger, and final reports were filed. Keep state administrative agency correspondence and FEMA-related approvals.

Use the [federal award closeout retention guide](/resources/guides/federal-award-closeout-document-retention-guide) to set the retention date. Keep equipment records active while the property is in use.

Brief leadership on the continuing duties. Security equipment may need maintenance, insurance, access controls, or inventory checks after the award ends. Write those duties down so they do not vanish when the project lead changes.
