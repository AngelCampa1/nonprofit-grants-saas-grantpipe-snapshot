# Nonprofit audit sample selection prep guide

Audit sample requests are stressful when evidence is scattered. They are manageable when the population is clean and each transaction has support. The auditor chooses the sample. The nonprofit controls how ready the records are.

Sample prep starts before selection. If staff wait until the auditor names the items, they may have to find old approvals, invoices, reports, and grant coding under fieldwork pressure.

## Clean the population first

The population is the full list the auditor will sample from. It may be all expenses, all payroll charges, all cash receipts, all journal entries, or all transactions charged to a federal award.

Before giving a population to the auditor, check it for scope:

- Correct fiscal year
- Correct grant period
- Correct fund or class code
- Correct transaction type
- No duplicate lines
- Voids and reversals labeled clearly
- Totals tied to the general ledger

Do not send a report you have not reviewed. If the auditor samples from a flawed population, the team may need to rebuild the file and explain the difference.

## Keep source records close to the transaction

For expense samples, the auditor may ask for the invoice, approval, payment proof, and grant support. For payroll samples, the auditor may ask for time records, pay rate approval, payroll register, and allocation support. For cash receipts, the auditor may ask for donor records, award letters, deposit support, and restriction terms.

Each transaction should answer three questions:

- What happened?
- Who approved it?
- Why was it coded this way?

The source files should make the answer clear without a long email. Use short notes when a transaction needs context.

## Prepare grant sample support

Grant samples need more than a normal invoice file. They need evidence that the cost belongs to the award. That may include the award budget, grant period, cost category, approval, and allowability review.

For federal awards, the file may also need procurement support, time records, or proof that the cost was not charged twice. The Uniform Guidance cost principles focus on whether costs are necessary, reasonable, allocable, and supported. Ask your auditor how those rules apply to a selected item.

GrantPipe helps teams keep grant compliance files, deadlines, restricted funds, audit evidence, and reporting records connected. That is useful when an expense sample needs both accounting support and grant context.

## Use one folder per selected item

When the sample arrives, create one folder for each selected item. Name the folder with the sample number, date, vendor or payee, amount, and ledger reference.

Inside the folder, add an index. The index can be a short text file or cover sheet:

- Sample number
- Ledger transaction ID
- Amount
- Account and grant code
- Files included
- Notes for timing or split coding

This helps the auditor review faster. It also helps staff see whether anything is missing before submission.

## Do a staff review before sending

Sample support should be reviewed before upload. The reviewer should check whether the amount, date, vendor, and code match the population. They should also check whether approval is dated and complete.

For restricted fund samples, confirm that the transaction agrees with the donor or grant restriction. For reporting samples, confirm that the amount ties to the report source schedule. For journal entries, confirm that support explains the reason for the entry.

If the file has a gap, do not hide it. Write a short note that explains what is missing and what staff did to resolve it. Ask the auditor whether more support is needed.

## Avoid oversharing

More files do not always help. Send what answers the request. Extra folders can slow review and expose data the auditor did not need.

If a file includes sensitive data, limit it to the requested scope. For example, a payroll sample may not need unrelated employee data. Follow your auditor's secure upload process.

## Track sample status

Add every selected item to a sample tracker. Use columns for sample number, population, owner, files ready, reviewer, submitted date, follow-up, and closed date.

This tracker keeps fieldwork moving. It also gives management a clear view of blockers. If many samples fail for the same reason, that may point to a larger process issue.

## Learn from follow-up

Auditor follow-up is a useful signal. If the same question comes up again, the file format may be weak. If approvals are missing, the purchase workflow may need a control. If grant coding is unclear, finance and program teams may need a shared review step.

After the audit, review all sample follow-up. Turn repeated questions into process changes before the next close cycle. The next audit will be easier if the evidence improves during normal work, not at fieldwork time.
