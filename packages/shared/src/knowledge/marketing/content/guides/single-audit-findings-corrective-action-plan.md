# Single audit findings corrective action plan

A single audit finding is not finished when the audit report is issued. The finding starts a repair cycle. Under 2 CFR 200.511, the auditee prepares a corrective action plan for each current-year finding. Federal agencies and pass-through entities use that plan to judge whether management understands the issue and has a real fix.

This guide is for the first draft and the follow-through. It pairs with the [common single audit findings guide](/resources/guides/common-single-audit-findings) and the [single audit threshold guide](/resources/guides/single-audit-threshold-1m).

## Start with the finding number

Use the exact finding number from the audit report. Include the federal program, Assistance Listing number, agency, and pass-through entity if there is one. This helps the agency, auditor, and board track the same issue.

Do not rename the finding in a way that softens it. If the report says "inadequate procurement documentation," use that language. The plan can explain context, but the title should stay traceable.

## State the root cause

The best corrective action plan starts with the cause, not the symptom. "Staff did not retain quotes" is a symptom. The cause may be that the purchasing policy does not name the file owner, the grant team does not know when federal rules apply, or the accounting system has no place to attach procurement records.

Write the root cause in plain language. Avoid blaming one person unless the evidence supports that. Most findings come from weak process design, unclear ownership, missing review, or training gaps.

## Describe the action

The action should change the process that caused the finding. If the finding was missing time records, the action is not "staff will be reminded." A better action is a new monthly certification workflow, reviewer signoff, and a report that lists missing certifications before payroll is finalized.

Strong actions are specific:

- Update the written policy
- Add a required approval step
- Build a standard file checklist
- Train staff who touch the process
- Review a sample before the next report
- Report status to leadership until closed

If the finding relates to subrecipient monitoring, use the [subrecipient risk assessment guide](/resources/guides/subrecipient-risk-assessment-scoring-guide) to tie the repair to risk-based monitoring.

## Name one accountable owner

The plan should name the responsible official. That person does not have to do every task, but they own completion. For finance findings, the owner may be the controller or finance director. For program reporting, it may be the grants manager. For board-level policy gaps, the executive director may need to own the fix.

Avoid group ownership such as "finance team." Groups do not answer follow-up questions. Name a person or role, then list supporting roles if needed.

## Set a real completion date

The expected completion date should match the work. A policy update may take 30 days. A system change may take 90 days. A control that needs two monthly cycles may need more time before it can be proven.

Do not set every action to the same date. That makes the plan look copied. Use milestones when the fix has stages: policy approved, staff trained, first review completed, first evidence sample retained.

## Define evidence before you start

A corrective action plan is only useful if you can prove the fix happened. Decide what evidence will close the item.

Examples:

- Approved policy version
- Training attendance list
- New checklist in completed award files
- Review log with exceptions resolved
- Screenshot or report from the system
- Sample of corrected transactions
- Board or audit committee minutes

Store this evidence with the finding. Do not wait until next year's audit to collect it.

## Track management decisions

For pass-through awards, the pass-through entity may issue a management decision. Federal agencies may also issue decisions. These decisions can sustain the finding, require repayment, require more action, or accept the plan.

Track the decision date, required actions, due dates, and correspondence. If the decision changes the plan, update the plan and keep both versions.

## Report progress to leadership

The board or audit committee should see open findings until they are closed. A simple status table works: finding number, owner, due date, status, next step, and evidence collected.

This is not about creating fear. It keeps the fix visible. Repeated findings are worse than first-time findings because they show management did not correct the problem.
