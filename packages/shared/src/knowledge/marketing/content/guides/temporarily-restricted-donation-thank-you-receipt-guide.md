Many nonprofits still say "temporarily restricted donation" even though current FASB presentation uses "net assets with donor restrictions." The plain meaning is familiar: the donor gave money that can only be used for a purpose, a period, or both.

The thank you receipt is not the full accounting record. It is still important. It may be the first written proof of donor intent that both the donor and nonprofit keep.

This guide explains how to write a clear receipt without adding promises the organization cannot track. It is not tax advice. Use the IRS rules and qualified advisors for specific receipt questions.

## Start with required gift facts

The IRS has written acknowledgment guidance for charitable contributions. A receipt should capture the basic facts accurately.

Include:

- Donor name
- Nonprofit legal name
- Gift date
- Cash amount or noncash description
- Statement about goods or services
- Signature or sender name
- Organization contact information

For noncash gifts, do not state a value unless your reviewed process allows it. The donor is usually responsible for valuation. Use advisor-reviewed language for unusual gifts.

## Reflect the restriction carefully

If the donor restricts the gift, the thank you can name that restriction. Keep the wording close to the donor's source document.

For example:

"Thank you for your gift of $5,000 received on June 29, 2026, restricted for the after-school reading program."

That is clear and factual. It does not promise a specific result. It does not expand the restriction.

Avoid language like "your gift will guarantee reading gains" unless the organization has approved support for that claim. Most receipts should thank, confirm, and stay narrow.

## Do not create a new restriction by accident

Sometimes staff add warm language that changes the meaning. A donor may give to a campaign generally, but the receipt says the gift is only for one program. That can create confusion later.

Before sending, compare the receipt to:

- Donor letter
- Online gift form
- Campaign page
- Pledge agreement
- Check memo
- Staff notes

If the receipt wording is broader or narrower than the source, fix it before sending.

## Add finance review for restricted gifts

Development should not be the only team that sees restricted receipt language. Finance needs to know how the gift will be tracked.

Finance should review:

- Restriction type
- Fund or project code
- Deposit coding
- Release method
- Reporting needs
- Evidence storage

## Keep the tone human and plain

A receipt can still sound like a real thank you. Use simple words. Keep the gratitude clear. Then state the gift facts.

Example structure:

- Thank the donor.
- State the gift amount and date.
- State the restriction, if any.
- State goods or services language.
- Add one short sentence about how the organization will use the support, only if it matches the restriction.
- Give a contact for questions.

Avoid heavy fundraising language in the receipt. Save bigger stories for a separate stewardship note when the facts are reviewed.

## Save the evidence

The receipt should be saved with the gift record. The source document should be saved too. If the donor later asks about the restriction, the team should be able to see exactly what was promised and what was acknowledged.

Save:

- Final receipt
- Donor source document
- Deposit record
- Finance review note
- Fund setup note
- Any donor clarification

This evidence helps at month end and year end. It also helps if staff change.

## Review old wording

If your templates still say "temporarily restricted," decide whether to keep that phrase for donor familiarity or update it. Finance statements now use "with donor restrictions" and "without donor restrictions" under FASB ASU 2016-14.

You can keep donor-facing wording plain while finance uses the correct reporting terms. For example, a receipt can say "restricted for the 2026 food pantry program" without using technical net asset language.

## Use a hold status when facts are unclear

Do not send a restricted receipt when the donor intent is unclear. Use a hold status and ask for clarification.

Common hold reasons include a vague check memo, conflicting email and form language, a campaign page that changed, or a donor request the organization may not be able to honor.

It is better to pause than to send a receipt that creates the wrong record.

A strong restricted donation receipt is simple. It thanks the donor, states the facts, keeps the promise narrow, and gives finance the evidence needed to track the gift.
