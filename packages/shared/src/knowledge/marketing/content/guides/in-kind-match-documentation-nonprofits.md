# In-kind match documentation for nonprofits

In-kind match can help a nonprofit meet a grant requirement without using cash. It can also create messy records if the team waits until the report is due.

The funder may allow donated goods, services, space, equipment, or volunteer time. The award terms decide what counts. The nonprofit still needs evidence that shows what was contributed, how it was valued, and how it supported the funded work.

This guide is an operating checklist, not legal or accounting advice. Follow the award terms, your accounting policy, and professional guidance.

## Read the match rule first

Do not start with what donors offered. Start with what the grant allows.

For federal awards, 2 CFR 200.306 covers cost sharing and matching. It includes rules for verifiable records and donated contributions. 2 CFR 200.434 covers contributions and donations as a cost principle topic. Other funders may use their own match terms.

Review:

- Allowed match types
- Ineligible match types
- Match period
- Required documentation
- Valuation rules
- Reporting format
- Approval rules
- Source limits

Save the rule in the grant file. Staff should not have to search for it each time a match record arrives.

## Create a match register

A match register is the control list for all match sources. It helps prevent missing support and double counting.

Include:

- Grant name
- Match source
- Type of contribution
- Date received or used
- Amount or value
- Valuation basis
- Program use
- Evidence file
- Reviewer
- Report period
- Status

Update the register monthly for active awards. If match is only reviewed at report time, gaps will appear too late.

GrantPipe can help connect match records with grant compliance tasks, restricted funds, deadlines, reports, and audit evidence. That connection is useful when in-kind support comes from program partners but must be reviewed by finance.

## Document donated goods

For donated goods, save records that show what was donated and how the value was set.

Evidence may include:

- Donor letter
- Description of goods
- Date received
- Condition
- Quantity
- Fair value support
- Program use note
- Receipt or acknowledgment record

Do not use a value just because it sounds reasonable. Keep the basis. That may be a price list, quote, invoice, catalog price, or other support allowed by policy.

## Document donated space

Donated space can be useful match when allowed. It also needs clear support.

Save:

- Space provider letter
- Location
- Dates and hours used
- Purpose
- Rate basis
- Comparable rental support if needed
- Program owner confirmation

If the space was used for both grant and non-grant work, document the allocation. Do not count the full value if only part of the use supported the funded work.

## Document volunteer time

Volunteer time is easy to overstate. Use time records.

Track:

- Volunteer name or approved identifier
- Date
- Hours
- Activity
- Grant or program supported
- Supervisor review
- Rate used
- Rate support

If skilled services are counted at a higher rate, keep support for why that rate applies. If the grant only allows certain volunteer work, make sure the activity description is clear.

## Document donated services

Donated professional services may include legal, accounting, consulting, design, training, or clinical work. Review the award terms and accounting policy before counting them.

Save:

- Provider name
- Service description
- Date
- Hours or deliverable
- Rate or value basis
- Evidence of service
- Program use
- Finance review

Do not count services that do not support the funded program. A donated service can be generous and still not count as match.

## Review before reporting

Before a grant report, finance and program staff should review the match register.

Ask:

- Is each source allowed?
- Is each date inside the match period?
- Is the value supported?
- Is the program use clear?
- Is the evidence saved?
- Has any source been counted elsewhere?
- Does the report total match the register?

Save the review note with the final report. If the funder asks for support, the team should be able to open the record without rebuilding it.

## Keep donor and grant records connected

Some in-kind support starts as a donor relationship. The donor CRM should show the relationship, contact, and acknowledgment status. The grant file should show whether the contribution counted as match.

Those are related records, not the same record. Development needs relationship history. Finance and grants need compliance support.

Good in-kind match documentation is boring on purpose. It names the source, value, use, review, and evidence. That is what makes the final report easier to trust.
