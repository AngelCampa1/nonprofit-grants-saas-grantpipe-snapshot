# Grant proposal budget review checklist

A grant proposal budget is a promise. If the award is funded, the nonprofit may need to track restricted funds, explain variances, support costs, and report results against that budget.

Do not treat the budget as an attachment that finance checks at the end. Review it while there is still time to change the proposal.

## Start with funder rules

Read the funding notice, application instructions, and budget form. For federal awards, 2 CFR Part 200 cost principles are important. Sections 200.403, 200.404, and 200.405 cover allowability, reasonable costs, and allocable costs.

Create a rule list:

- Allowed cost categories
- Unallowed cost categories
- Indirect cost rule
- Match requirement
- Budget period
- Minimum and maximum request
- Required budget narrative
- Prior approval items
- Required attachments

Do this before numbers are final. A rule found late can force a rushed rewrite.

## Check that the budget matches the narrative

The budget and narrative should describe the same work.

Ask:

- Does each activity have a cost?
- Does each major cost appear in the work plan?
- Are staffing levels realistic?
- Are supplies tied to program use?
- Are contractor costs explained?
- Are participant costs allowed?
- Are equipment costs justified?

If the narrative promises three workshops, the budget should support three workshops. If the budget includes a program coordinator, the narrative should explain that role.

## Review personnel costs

Personnel is often the largest grant cost. It also needs careful support.

Check:

- Position title
- Salary basis
- Percent of time
- Grant period
- Fringe calculation
- Role in the program
- Timekeeping or allocation method

Do not budget staff time just because the grant can pay for it. The role should be needed for the work and trackable during the grant.

## Review non-personnel costs

For each non-personnel line, ask whether the cost is needed, reasonable, allocable, and supported.

Review:

- Supplies
- Travel
- Equipment
- Occupancy
- Contract services
- Training
- Printing
- Software
- Other direct costs

Write the basis for each estimate. Use vendor quotes, prior invoices, travel rules, rental rates, or other support when available. Do not invent precision. If the amount is an estimate, say how it was estimated.

## Check indirect costs

Indirect costs can help cover shared costs, but the rules vary. Some funders allow a negotiated rate. Some allow a de minimis rate. Some cap or exclude indirect costs.

Before submission, finance should confirm:

- Rate or calculation
- Cost base
- Exclusions
- Funder cap
- Documentation
- Board or policy support if needed

If indirect costs are not included, document why. Some nonprofits leave money out of budgets because the rule is unclear. That can create pressure on unrestricted funds later.

## Review match and cost share

Do not promise match without a tracking plan.

For each match source, record:

- Cash or in-kind
- Source
- Amount
- Valuation basis
- Owner
- Evidence needed
- Timing
- Restrictions

If the match depends on another grant, donation, volunteer service, or donated space, confirm that the source can be used. Finance should review match before the proposal is submitted.

## Prepare for restricted fund tracking

Ask what will happen if the award is funded.

The budget should be ready to become an operating record:

- Fund or project code
- Budget categories
- Reporting periods
- Approval workflow
- Reimbursement process
- Evidence folder
- Deadline calendar

GrantPipe can help connect proposal budgets, restricted funds, grant compliance deadlines, documents, and audit evidence. The cleaner the proposal budget is, the easier the funded award is to manage.

## Add a handoff note for finance

A proposal budget is not just a submission file. It becomes the first version of the award budget if the funder says yes. Add a short handoff note before submission so finance does not have to reverse engineer the proposal later.

The note should explain which costs are new, which costs are already in the operating budget, which costs depend on hiring, and which costs need a new fund or project code. It should also flag any cost that may need prior approval after award.

## Set the final review path

Before submission, require signoff from:

- Program owner
- Finance reviewer
- Grants lead
- Executive director if required

Each reviewer should know what they are checking. Program confirms the work. Finance confirms the numbers and tracking plan. Grants confirms the funder instructions and deadline.

Save the final budget, budget narrative, review notes, and submission proof. If the award is funded, those records become the starting point for budget to actual review.

## Keep the submitted version easy to find

After submission, save the exact budget that went to the funder. Do not keep only the working sheet. The funded award may be compared to the submitted file months later, and staff need to know which version the funder saw.

Save the spreadsheet, budget narrative, portal confirmation, and any funder response in the grant file. If the funder asks for a revised budget before award, save that version beside the original and label both files by date.
