# Year-end restricted fund rollforward guide

The year-end restricted fund rollforward explains why restricted balances changed. It should show the beginning balance, new restricted gifts or grants, releases, corrections, and ending balance for each restriction. Auditors use it to test classification, releases, and support.

The rollforward is also useful for board reporting. It helps leaders see which funds are available for restricted work, which grants are waiting on reimbursement, and which balances need review.

## Start with last year's ending balance

The beginning balance should match the prior year audited financial statements or final close file. If it does not, stop and explain the difference before adding current year activity.

Use one row for each restricted fund, grant, or donor restriction. Each row should have a name, source, restriction type, owner, and status.

Common restriction types include purpose restriction, time restriction, and combined time and purpose restriction. Some grant agreements may also include conditions. Conditions can affect revenue recognition. Ask your CPA how to handle conditional grants.

## Add current year restricted activity

New activity should tie to source records. Use gift letters, grant agreements, award notices, cash receipts, receivable support, and board records when needed.

Add columns for:

- New restricted gifts
- New restricted grants
- Receivables recorded
- Cash received
- Corrections into restricted balance
- Notes for conditions or timing

Do not record a restricted amount just because a staff member says the money is for a program. The restriction should come from the donor or grant terms.

## Track releases from restriction

A release happens when the restriction is met. That may happen because time passed, the nonprofit incurred qualifying expenses, or both.

Each release should tie to a release journal entry and support. For expense-based releases, link to the qualifying expense detail. For time-based releases, show the period covered. For grants, link to budget and award terms.

Review releases before year-end close. Missed releases can overstate restricted balances. Early releases can understate them.

## Separate cash from restricted balance

Restricted cash and restricted net assets are related, but they are not the same thing. A reimbursable grant may have restricted work with no cash yet. An advance may create cash before the nonprofit has met the purpose. A pledge may create a receivable.

The rollforward should include columns for cash, receivable, expenses, and ending restricted balance. This helps finance explain why the bank balance does not equal the restriction balance.

GrantPipe can help teams connect donor CRM records, grant compliance, restricted funds, deadlines, audit evidence, and reporting. That helps the finance team see the records behind each balance instead of working from a disconnected spreadsheet.

## Add correction columns

Year-end review often finds coding errors. Add columns for corrections into and out of restricted balance. Each correction should have a note and support.

A correction note should answer:

- What was wrong?
- How was it found?
- What entry fixed it?
- Did it affect a grant report?
- Did it affect board reporting?

If a correction affects a prior report to a funder, ask the funder or auditor how to handle it. Do not quietly change a report without review.

## Reconcile to the ledger and financial statements

The ending restricted balance should tie to the general ledger and financial statements. If the statement line is summarized, keep the detail schedule behind it.

Tie these totals:

- Beginning restricted balance
- Current year additions
- Releases
- Ending restricted balance
- Related receivables
- Related cash, if tracked

Document any mapping between fund codes, grant codes, and financial statement lines.

## Review material balances

Large and old balances need review. A restricted balance that has not moved in a long time may need research. It may be waiting on a release, missing activity, or tied to a restriction that still applies.

For each material balance, keep the source agreement and a short status note. The board treasurer or finance committee may need to see the largest balances and any exceptions.

## Save the final file with audit support

At close, save the rollforward, source schedules, release entries, correction notes, and reviewer signoff. Use the same file in the audit binder.

Next year, begin with the final audited balance. The best rollforward is maintained monthly, but even a year-end rollforward can work if the source records are clear and the review is careful.

A restricted fund rollforward should be plain enough that a new reviewer can follow it. It starts with the prior balance, shows what changed, proves releases, and ties to the ending financial statement amount.
